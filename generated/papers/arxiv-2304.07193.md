## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Thesis: the goal is general-purpose visual features that work across image distributions and tasks without fine-tuning; the paper shows that existing self-supervised methods can produce such features if trained on enough curated data from diverse sources.([Abstract, p.1](https://arxiv.org/pdf/2304.07193v2#page=1 "This work shows that existing pretraining methods, especially self-supervised methods, can produce such features if trained on enough curated data from diverse sources."))
- **c2** Data pipeline: the uncurated source is 1.2B unique images collected from a publicly available repository of crawled web data (with NSFW filtering and face blurring); near-duplicates are removed, including near-duplicates of test or validation images of any benchmark used; images close to curated datasets (ImageNet-22k, the ImageNet-1k train split, Google Landmarks and fine-grained datasets) are retrieved using embeddings of a self-supervised ViT-H/16 pretrained on ImageNet-22k. No statement that LVD-142M itself is released was found (searched for release, publicly, private).([Data Processing, p.5](https://arxiv.org/pdf/2304.07193v2#page=5 "We also remove near-duplicates of images contained in the test or validation set of any benchmark used in this work."))
- **c3** Data ablation (ViT-g/14, same number of iterations, shorter than the final run): curated data works better on most benchmarks than 142M randomly sampled uncurated images from the same source; compared with ImageNet-22k, LVD-142M is better on all benchmarks except ImageNet-1k, including domains not used for curation (iNaturalist 2018/2021, Places205).([Ablation Studies (Pretraining Data Source), p.8](https://arxiv.org/pdf/2304.07193v2#page=8 "The most salient observation is that training on a curated set of images works better on most benchmarks than training on uncurated data."))
- **c4** Method: the image-level DINO loss (student/teacher class tokens, EMA teacher) and the patch-level iBOT loss (masked student patches predicted against the teacher's visible patches) are combined, with SwAV's Sinkhorn-Knopp centering instead of softmax-centering, a KoLeo regularizer that spreads features within a batch, and a short 518x518 phase at the end. Smaller models are distilled from the ViT-g rather than trained from scratch.([Discriminative Self-supervised Pre-training, p.5](https://arxiv.org/pdf/2304.07193v2#page=5 "We learn our features with a discriminative self-supervised method that can be seen as a combination of DINO and iBOT losses with the centering of SwAV (Caron et al., 2020)."))
- **c5** Recipe ablation (ViT-L on ImageNet-22k, from iBOT to DINOv2) was optimized for ImageNet-1k k-NN accuracy, because in the authors' experience the linear probe is lower-bounded by k-NN; LayerScale and high stochastic depth lowered linear-probe accuracy but were kept because they avoid NaN losses (training stability).([Table 1, p.8](https://arxiv.org/pdf/2304.07193v2#page=8 "We optimize for k-NN performance, as in our experience, the linear probe performance is lower-bounded by the k-NN performance."))
- **c6** Linear-probe protocol: a linear layer on frozen features trained with SGD for 12500 iterations with random-resized-crop augmentation, with a grid search over 13 learning rates, output layers {1, 4} and whether average-pooled patch tokens are concatenated to the class token; the highest accuracy on the validation set is reported. All compared models, including weakly-supervised ones, were evaluated with the authors' code.([Appendix B.3, p.31](https://arxiv.org/pdf/2304.07193v2#page=31 "We then report the highest accuracy value obtained on the validation set as is common practice."))
- **c7** Because most SSL methods were developed using ImageNet-1k validation accuracy as a debugging signal, the authors additionally report ImageNet-ReaL and ImageNet-V2 accuracy; they note the linear model is used for simplicity and reproducibility even though classes may not be linearly separable.([Results (ImageNet Classification), p.11](https://arxiv.org/pdf/2304.07193v2#page=11 "Because most SSL methods were developped using ImageNet-1k validation performance as a debugging signal, we also report the top-1 accuracy on ImageNet-ReaL and ImageNet-V2."))
- **c8** Fine-tuning sanity check (not core to the paper): to check whether the models were involuntarily specialized to linear evaluation, they apply the fine-tuning pipeline of Touvron et al. (2022) without tweaking hyper-parameters; ImageNet-1k accuracy improves by more than 2% over the linear probe, which the authors describe as only modest, concluding that fine-tuning is optional.([Results (Can we finetune the encoders?), p.12](https://arxiv.org/pdf/2304.07193v2#page=12 "As DINOv2 leads to features that are strong in both the linear and finetuning settings, a strong property of our approach is that finetuning is optional."))
- **c9** Compute: the whole project is estimated at 0.5k to 1k tCO2eq, in the order of 200k GPU-days; one ViT-g pre-training takes 22k GPU-hours (A100). The estimate only counts GPU electricity.([Estimating the Environmental Impact of Training our Models, p.21](https://arxiv.org/pdf/2304.07193v2#page=21 "For example, a single pre-training of a ViT-g model (22k GPU-hours) emits 3.7 tons of CO2eq, while a finetuning on ImageNet-1k (1k GPU-hours) emits 0.2 tons."))
