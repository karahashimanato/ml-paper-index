## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Contribution (classical algorithm: Marker algorithm for paging): Marker is modified to use predicted next-arrival times, with a competitive ratio that decreases as the oracle error decreases and is always capped by O(log k), achievable without any oracle.([Abstract, p.1](https://arxiv.org/pdf/1802.05399v4#page=1 "Instead we show how to modify the Marker algorithm to take into account the oracle’s predictions, and prove that this combined approach achieves a competitive ratio that both decreases as the oracle’s error decreases, and is always capped by O(log k), which can be achieved without any oracle input."))
- **c2** Prediction model assumption: the oracle is treated as a black box, not dependent on its inner workings or the exact distribution of its errors; guarantees are parametric in its total error under a chosen loss (the analysis covers e.g. absolute and squared loss on the predicted next arrival time), normalized by the optimal cost (an eps-accurate predictor has error at most eps * Opt on every input sequence).([Abstract, p.1](https://arxiv.org/pdf/1802.05399v4#page=1 "Our approach treats the oracle as a complete black box, and is not dependent on its inner workings, or the exact distribution of its errors."))
- **c3** Naive use fails: blindly evicting the element predicted furthest in the future (Belady's rule on predictions, 'algorithm B') is consistent, but under absolute loss its competitive ratio is Omega(eps) in the normalized error eps (Proposition 3.1), so it becomes unbounded when the predictor's error is much worse than the offline optimum; the abstract adds that this can happen even when the average error is quite low.([Abstract, p.1](https://arxiv.org/pdf/1802.05399v4#page=1 "We demonstrate that naively following the oracle’s recommendations may lead to very poor performance, even when the average error is quite low."))
- **c4** Main theorem and its assumptions (Theorem 3.3): for a predictor of the next arrival of each requested element that is eps-accurate (total loss at most eps * Opt on every sequence) and any loss whose spread S_l is bounded by a concave function, the competitive ratio of eps-assisted Predictive Marker is at most 2*min(1 + 2S_l(eps), 2H_k). Predictive Marker is randomized (random evictions after a chain reaches length H_k), and the O(H_k) cap is stated as holding in expectation. For absolute loss this gives min(2 + 2 sqrt(5 eps), 4H_k) (Corollary 1). Section 3.5 extends the result to predictors that are eps-accurate only in expectation.([Main result: Predictive Marker, p.15](https://arxiv.org/pdf/1802.05399v4#page=15 "Consider the caching problem Π with n requests and cache size k, the prediction model H that predicts the next arrival of a requested element and any loss function ℓwith spread bounded by Sℓfor some function Sℓthat is concave in its argument."))
- **c5** Tightness (Theorem 3.4): any deterministic eps-assisted marking algorithm that uses the predictor only for deterministic tie-breaking among unmarked elements has competitive ratio Omega(min(S_l(eps), k)), so the robustness rate of Predictive Marker cannot be improved that way; the authors conjecture that a rate of log(1 + sqrt(eps)) for absolute loss is possible with randomized use of the predictor and note that subsequent work by Rohatgi proved refined upper and lower bounds.([Tightness of analysis, p.17](https://arxiv.org/pdf/1802.05399v4#page=17 "Theorem 3.4 establishes that the analysis of Predictive Marker is tight with respect to the rate of robustness, and suggests that algorithms that use the predictor in a deterministic manner may suﬀer from similar rates."))
- **c6** Synthetic prediction noise (empirical protocol): predictions are the true next arrival time plus i.i.d. lognormal noise (mean parameter 0, standard deviation sigma), chosen to showcase the effect of rare but large failures of the learning algorithm; the metric ('competitive ratio') is the number of misses divided by the optimal number of misses on real request sequences (BrightKite, CitiBike).([Experiments, p.22](https://arxiv.org/pdf/1802.05399v4#page=22 "To simulate the performance of an ML system, we set h(t) = y(t) + ϵ, where ϵ is drawn i.i.d. from a lognormal distribution with mean parameter 0 and standard deviation σ."))
- **c7** Off-the-shelf predictor result (empirical): with the published PLECO repeat-consumption model adapted to predict the next appearance (not tuned or optimized for that task), Predictive Marker outperforms LRU, Marker and Blind Oracle; the authors say the gains over LRU appear modest but are statistically significant at p < 0.001. In the experiments Predictive Marker's switching point is set to k, so it never switches to random evictions, i.e. a different configuration from the H_k switching point analyzed in Theorem 3.3.([Results, p.23](https://arxiv.org/pdf/1802.05399v4#page=23 "While the gains appear modest, we note they are statistically signiﬁcant at p < 0.001."))
