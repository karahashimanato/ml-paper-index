## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Layer rule: the GCN propagation rule is H^(l+1) = sigma(D~^-1/2 A~ D~^-1/2 H^(l) W^(l)), where A~ = A + I_N is the adjacency matrix of the undirected graph with added self-connections, D~_ii = sum_j A~_ij, W^(l) is a layer-specific trainable weight matrix and H^(0) = X; the authors state this form can be motivated via a first-order approximation of localized spectral filters (citing Hammond et al., 2011; Defferrard et al., 2016).([Section 2, p.2](https://arxiv.org/pdf/1609.02907v4#page=2 "We consider a multi-layer Graph Convolutional Network (GCN) with the following layer-wise propagation rule:"))
- **c2** Starting point of the derivation: spectral convolution g_theta * x = U g_theta U^T x on the eigenvectors of the normalized Laplacian L = I_N - D^-1/2 A D^-1/2 costs O(N^2) and needs an eigendecomposition; following the suggestion of Hammond et al. (2011), the filter is approximated by a truncated Chebyshev expansion of order K in the rescaled Laplacian, which is K-localized (depends only on nodes at most K steps away) and costs O(|E|); Defferrard et al. (2016) used this K-localized convolution to define a CNN on graphs.([Section 2.1, p.2](https://arxiv.org/pdf/1609.02907v4#page=2 "Note that this expression is now K-localized since it is a Kth-order polynomial in the Laplacian, i.e. it depends only on nodes that are at maximum K steps away from the central node (Kth-order neighborhood)."))
- **c3** First-order simplification: the layer-wise convolution is limited to K = 1 and lambda_max is approximated by 2 (expecting the network parameters to adapt to the change of scale), giving theta'_0 x - theta'_1 D^-1/2 A D^-1/2 x; constraining to a single parameter theta = theta'_0 = -theta'_1 gives theta (I_N + D^-1/2 A D^-1/2) x.([Section 2.2, p.3](https://arxiv.org/pdf/1609.02907v4#page=3 "In this linear formulation of a GCN we further approximate λmax ≈2, as we can expect that neural network parameters will adapt to this change in scale during training."))
- **c4** Renormalization trick: I_N + D^-1/2 A D^-1/2 has eigenvalues in [0, 2], so repeated application can lead to numerical instabilities and exploding/vanishing gradients in a deep model; the authors therefore replace it by D~^-1/2 A~ D~^-1/2 with A~ = A + I_N. The generalized filtering Z = D~^-1/2 A~ D~^-1/2 X Theta has complexity O(|E| F C).([Section 2.2, p.3](https://arxiv.org/pdf/1609.02907v4#page=3 "Repeated application of this operator can therefore lead to numerical instabilities and exploding/vanishing gradients when used in a deep neural network model."))
- **c5** Setting: the authors position their work, in contrast to Bruna et al. (2014) and Defferrard et al. (2016), as transductive node classification within much larger networks, and state that a number of simplifications to those frameworks improve scalability and classification performance in large-scale networks.([Section 4.2, p.5](https://arxiv.org/pdf/1609.02907v4#page=5 "In contrast to these works, we consider here the task of transductive node classiﬁcation within networks of signiﬁcantly larger scale."))
- **c6** Evaluation protocol: a two-layer GCN is evaluated on a test set of 1,000 labeled examples using the same dataset splits as Yang et al. (2016), with an additional validation set of 500 labeled examples used for hyperparameter optimization (dropout, L2 factor of the first layer, hidden units) but not for training; for the citation datasets hyperparameters are optimized on Cora only and reused for Citeseer and Pubmed; training runs up to 200 epochs with Adam (learning rate 0.01) and early stopping with a window of 10.([Section 5.2, p.6](https://arxiv.org/pdf/1609.02907v4#page=6 "We choose the same dataset splits as in Yang et al. (2016) with an additional validation set of 500 labeled examples for hyperparameter optimization (dropout rate for all layers, L2 regularization factor for the ﬁrst GCN layer and number of hidden units)."))
- **c7** Comparison of propagation models (same set-up, mean of 100 runs with random weight initializations): the authors state that the renormalized propagation model offers both improved efficiency (fewer parameters and operations) and better predictive performance on a number of datasets than a naive 1st-order model or higher-order Chebyshev graph convolutions.([Section 7.1, p.8](https://arxiv.org/pdf/1609.02907v4#page=8 "We have further demonstrated that the proposed renormalized propagation model (Eq. 8) offers both improved efﬁciency (fewer parameters and operations, such as multiplication or addition) and better predictive performance on a number of datasets"))
- **c8** Stated limitations: full-batch training memory grows linearly with the dataset size (mini-batch SGD would need to account for the K-th order neighborhood of a K-layer GCN); the framework does not naturally support edge features and is limited to undirected graphs; and the approximations implicitly assume locality and equal importance of self-connections vs. edges to neighbors, for which the authors suggest a trade-off parameter lambda in A~ = A + lambda I_N that could be learned by gradient descent.([Section 7.2, p.8](https://arxiv.org/pdf/1609.02907v4#page=8 "Through the approximations introduced in Section 2, we implicitly assume locality (dependence on the Kth-order neighborhood for a GCN with K layers) and equal importance of self-connections vs. edges to neighboring nodes."))
- **c9** Depth: in a separate 5-fold cross-validation experiment on Cora, Citeseer and Pubmed using all labels (400 epochs without early stopping), the best results were obtained with 2- or 3-layer models; for models deeper than 7 layers, training without residual connections can become difficult, and overfitting can become an issue as parameters increase with depth.([Appendix B, p.14](https://arxiv.org/pdf/1609.02907v4#page=14 "We observe that for models deeper than 7 layers, training without the use of residual connections can become difﬁcult, as the effective context size for each node increases by the size of its Kth-order neighborhood (for a model with K layers) with each additional layer."))
