## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Framing: given a fitted model and a small set of fresh i.i.d. calibration pairs unseen during training (e.g. about 500), split conformal prediction returns sets with 1 - alpha <= P(Y_test in C(X_test)) <= 1 - alpha + 1/(n+1); the authors call this marginal coverage because the probability is averaged over the randomness in the calibration and test points.([Section 1 (Conformal Prediction), p.4](https://arxiv.org/pdf/2107.07511v6#page=4 "In words, the probability that the prediction set contains the correct label is almost exactly 1 −α; we call this property marginal coverage, since the probability is marginal (averaged) over the randomness in the calibration and test points."))
- **c2** Assumptions of the guarantee: Theorem 1 (attributed to Vovk, Gammerman and Saunders) assumes the calibration pairs and the test pair are i.i.d.; the appendix restates it and remarks that it also holds under the weaker condition of exchangeability. The proof given handles only the case of distinct scores (ties are referred to another work), and the upper bound needs a tie-breaking randomization that the authors say is usually ignored in practice.([Appendix D, p.50](https://arxiv.org/pdf/2107.07511v6#page=50 "As a technical remark, the theorem also holds if the observations to satisfy the weaker condition of exchangeability; see [1]."))
- **c3** The guarantee holds for any score function, but the usefulness of the sets depends on it: if the scores rank inputs by magnitude of model error, sets are smaller for easy inputs and bigger for hard ones; if the scores are random noise, the sets are a random sample of the label space just large enough for valid marginal coverage.([Section 1 (Choice of score function), p.6](https://arxiv.org/pdf/2107.07511v6#page=6 "although the guarantee always holds, the usefulness of the prediction sets is primarily determined by the score function."))
- **c4** What is not guaranteed: conditional coverage P[Y_test in C(X_test) | X_test] >= 1 - alpha is stronger than the marginal coverage conformal prediction achieves and, citing Vovk [14], is impossible to achieve in the most general case, so procedures must be checked for how close they come. Example given: if sets always cover group A (90% of people) and never cover group B (10%), marginal coverage is 90% but conditional coverage fails.([Section 3 (Evaluating Conformal Prediction), p.13](https://arxiv.org/pdf/2107.07511v6#page=13 "This is a stronger property than the marginal coverage property in (1) that conformal prediction is guaranteed to achieve—indeed, in the most general case, conditional coverage is impossible to achieve [14]."))
- **c5** Evaluation advice on set size and adaptivity: the procedure with the smallest average set size is not necessarily the best; sets should be small on easy and large on hard inputs, which the coverage guarantee does not imply. Suggested checks are set-size histograms, a feature-stratified coverage metric (minimum coverage over predefined groups) and a size-stratified coverage metric (minimum coverage over set-size bins), with the caveat that a good spread of set sizes does not by itself show that large sets occur for hard examples.([Section 3 (Evaluating Conformal Prediction), p.12](https://arxiv.org/pdf/2107.07511v6#page=12 "It is extremely important to keep in mind that the conformal prediction procedure with the smallest average set size is not necessarily the best."))
- **c6** Calibration set size: the guarantee holds for any n, but coverage conditional on a fixed calibration set is random (Beta(n + 1 - l, l) with l = floor((n+1) alpha), citing Vovk); the authors' rough guideline is that about n = 1000 calibration points suffices for most purposes, and the n needed for coverage within 1 - alpha +/- epsilon with probability 1 - delta can be computed explicitly.([Section 3.2, p.14](https://arxiv.org/pdf/2107.07511v6#page=14 "Roughly speaking, our conclusion will that be choosing a calibration set of size n = 1000 is suﬃcient for most purposes."))
- **c7** Checking correct coverage: run the procedure over R random calibration/validation splits of the available data (caching scores), and check that the histogram of empirical coverages is centered near 1 - alpha; finite n, n_val and R cause benign fluctuations, and the authors note these evaluations are computationally intensive (at least 100 splits).([Checking for Correct Coverage, p.15](https://arxiv.org/pdf/2107.07511v6#page=15 "So, we compute the coverage values by randomly splitting the n + nval data points R times into calibration and validation datasets, then running conformal."))
- **c8** Cost of data splitting: split conformal prediction needs only one model fit but sacrifices statistical efficiency by splitting data into training and calibration sets; full conformal prediction avoids splitting at the cost of many more model fits, and cross-conformal and CV+/Jackknife+ lie in between.([Section 6.2, p.28](https://arxiv.org/pdf/2107.07511v6#page=28 "Split conformal prediction requires only one model ﬁtting step, but sacriﬁces statistical eﬃciency."))
- **c9** Distribution shift breaks the standard guarantee: Theorem 1 assumes test points come from the same distribution as the calibration points. Weighted conformal prediction handles covariate shift using the likelihood ratio dP_test/dP, which the authors describe as a somewhat restricted case (a known covariate shift).([Conformal Prediction Under Covariate Shift, p.20](https://arxiv.org/pdf/2107.07511v6#page=20 "All previous conformal methods rely on Theorem 1, which assumes that the incoming test points come from the same distribution as the calibration points."))
- **c10** Conformal score in the classification example: s_i = 1 - fhat(X_i)_{Y_i}, one minus the softmax output of the true class, which is high when the model is badly wrong.([Section 1 (Conformal Prediction), p.4](https://arxiv.org/pdf/2107.07511v6#page=4 "The score is high when the softmax output of the true class is low, i.e., when the model is badly wrong."))
- **c11** Calibration quantile: qhat is the ceil((n+1)(1-alpha))/n empirical quantile of the calibration scores s_1, ..., s_n, i.e. essentially the 1 - alpha quantile with a small correction.([Section 1 (Conformal Prediction), p.4](https://arxiv.org/pdf/2107.07511v6#page=4 "Next comes the critical step: deﬁne ˆq to be the ⌈(n+1)(1−α)⌉/n empirical quantile of s1, ..., sn, where ⌈·⌉is the ceiling function (ˆq is essentially the 1 −α quantile, but with a small correction)."))
- **c12** Prediction set: C(X_test) = {y : fhat(X_test)_y >= 1 - qhat}, the classes with a high enough softmax output; this procedure is guaranteed to satisfy the coverage property (1) regardless of the model or the (unknown) data distribution.([Section 1 (Conformal Prediction), p.4](https://arxiv.org/pdf/2107.07511v6#page=4 "Remarkably, this algorithm gives prediction sets that are guaranteed to satisfy (1), no matter what (possibly incorrect) model is used or what the (unknown) distribution of the data is."))
