## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Definitions: aleatoric uncertainty captures noise inherent in the observations (e.g. sensor or motion noise) and cannot be reduced by collecting more data; epistemic uncertainty is uncertainty in the model parameters, which can be explained away given enough data. Aleatoric uncertainty is further split into homoscedastic (constant) and heteroscedastic (input-dependent).([Introduction, p.1](https://arxiv.org/pdf/1703.04977v2#page=1 "This could be for example sensor noise or motion noise, resulting in uncertainty which cannot be reduced even if more data were to be collected."))
- **c2** How each is modelled: epistemic uncertainty by a prior over weights with dropout variational inference (MC dropout); aleatoric uncertainty by placing a distribution over the model output and learning its variance as a function of the input with MAP inference, which on its own does not capture epistemic uncertainty.([Section 2.2, p.4](https://arxiv.org/pdf/1703.04977v2#page=4 "This approach does not capture epistemic model uncertainty, as epistemic uncertainty is a property of the model and not of the data."))
- **c3** Learned loss attenuation: predicting the (log) variance tempers the residual loss per input, so inputs with high predicted uncertainty have less effect on the loss, while the log-variance term penalizes predicting high uncertainty everywhere; no uncertainty labels are needed. The classification analogue places Gaussian noise on the logits and samples only the logits, which the authors say does not significantly increase test time.([Section 3, p.5](https://arxiv.org/pdf/1703.04977v2#page=5 "This makes the model more robust to noisy data: inputs for which the model learned to predict high uncertainty will have a smaller effect on the loss."))
- **c4** Protocol: DenseNet adapted for dense prediction (own implementation), MC dropout with p = 0.2 after each convolutional layer and 50 samples; aleatoric losses are derived with a Laplacian rather than Gaussian likelihood (L1 on residuals), which deviates from the Gaussian derivation. Datasets: CamVid and NYUv2 (segmentation), Make3D and NYUv2 Depth (depth regression).([Section 4, p.6](https://arxiv.org/pdf/1703.04977v2#page=6 "However, we derive the loss function using a Laplacian prior, as opposed to the Gaussian prior used for the derivations in §3."))
- **c5** On CamVid, modelling aleatoric uncertainty improves more than modelling epistemic uncertainty and combining both improves further; the authors take this to suggest epistemic uncertainty can be mostly explained away in this large-data setting (per-pixel prediction).([Semantic Segmentation, p.7](https://arxiv.org/pdf/1703.04977v2#page=7 "This shows that for this application it is more important to model aleatoric uncertainty, suggesting that epistemic uncertainty can be mostly explained away in this large data setting."))
- **c6** Precision-recall curves for aleatoric-only and epistemic-only models are very similar, which the authors say suggests that when only one uncertainty is modelled it attempts to compensate for the missing one when possible.([Quality of Uncertainty Metric, p.8](https://arxiv.org/pdf/1703.04977v2#page=8 "This suggests that when only one uncertainty is explicitly modeled, it attempts to compensate for the lack of the alternative uncertainty when possible."))
- **c7** Calibration evaluation: classification calibration plots are formed by binning predicted probabilities over all classes and all pixels of the test set and plotting the frequency of correct labels per bin (the number of bins is not stated in the text); regression calibration compares the frequency of residuals within thresholds of the predicted distribution.([Quality of Uncertainty Metric, p.8](https://arxiv.org/pdf/1703.04977v2#page=8 "To form calibration plots for classiﬁcation models, we discretize our model’s predicted probabilities into a number of bins, for all classes and all pixels in the test set."))
- **c8** Distance from training data (Table 3, reduced training sets and unrelated test datasets): aleatoric uncertainty stays roughly constant with more data, epistemic uncertainty decreases with more data and increases considerably on test points far from the training set, so aleatoric uncertainty alone cannot identify out-of-data examples.([Uncertainty with Distance from Training Data, p.9](https://arxiv.org/pdf/1703.04977v2#page=9 "Testing the models with a different test set (bottom two lines) shows that epistemic uncertainty increases considerably on those test points which lie far from the training sets."))
- **c9** Cost: aleatoric models add negligible compute, but epistemic models require MC dropout sampling; for DenseNet, where the entire architecture must be sampled, this is hard to parallelize due to GPU memory and often gives a 50x slow-down for 50 samples (cheaper for models with dropout only in the last layers). The authors leave real-time epistemic uncertainty as future work.([Real-Time Application, p.9](https://arxiv.org/pdf/1703.04977v2#page=9 "This is difﬁcult to parallelize due to GPU memory constraints, and often results in a 50× slow-down for 50 Monte Carlo samples."))
