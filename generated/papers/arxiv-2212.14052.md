## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Expressivity gap: on two synthetic tasks (induction head, associative recall), two-layer S4D and Gated State Spaces fail, which the authors say suggests they may not have the expressivity for general language; they argue this points to two missing capabilities, which attention has via the QK^T matrix (comparison) and copying with softmax(QK^T)V (recall).([Section 3.1, p.4](https://arxiv.org/pdf/2212.14052v3#page=4 "We argue that these failures suggest two missing capabilities: (i) to remember tokens that appear after a particular event (e.g., the special token in the induction head task), and (ii) to compare tokens across the sequence (e.g., comparing keys to decide which value to recall)."))
- **c2** H3 definition: the input is projected to Q, K, V; the feature map phi(K) of linear attention is replaced by a shift-matrix SSM and the running sum S_i by a diagonal SSM, giving Q ⊙ SSM_diag(SSM_shift(K) ⊙ V) for head dimension 1; the shift SSM can detect when an event occurs and the diagonal SSM (initialized from S4D's diagonal HiPPO) can remember a token for the rest of the sequence.([Section 3.2, p.5](https://arxiv.org/pdf/2212.14052v3#page=5 "H3 is loosely inspired by linear attention (Section 2): we project the input u to get three signals Q, K, V."))
- **c3** OpenWebText (12-layer models of about 125M parameters, same hyperparameters, 50B tokens): pure H3 is stated to come within 0.4 perplexity of Transformers and to be 3 to 3.9 points better than S4D and GSS.([Section 3.3, p.6](https://arxiv.org/pdf/2212.14052v3#page=6 "H3 comes within 0.4 perplexity points of Transformers when trained for 50B tokens on OpenWebText"))
- **c4** Hybrid: a model that keeps two self-attention layers (the second layer and layer 2 + N/2) and uses H3 elsewhere is stated to outperform Transformers on OpenWebText by 1.0 perplexity point (described as surprising) and to outperform the GSS-attention hybrid.([Section 3.3, p.6](https://arxiv.org/pdf/2212.14052v3#page=6 "A simple hybrid H3-attention language model surprisingly outperforms Transformers on OpenWebText by 1.0 point."))
- **c5** FlashConv cost trade-off: the block FFT writes the FFT as block-diagonal matrix multiplications (Cooley-Tukey) so tensor cores can be used, at O(N r log N / log r) FLOPs, more than a standard FFT; kernel fusion follows FlashAttention to avoid GPU memory reads/writes, and for sequences longer than 8K (which no longer fit in SRAM) a state-passing algorithm computes chunks of FFT convolution connected by the recurrence (Proposition 2: same output as the full SSM).([Section 4.1, p.7](https://arxiv.org/pdf/2212.14052v3#page=7 "This incurs more FLOPs than standard FFT (O(N log N)), but can run faster when we using specialized matrix multiplication hardware."))
- **c6** Pile evaluation protocol: hybrid H3-attention models at 125M, 355M, 1.3B and 2.7B are trained on the Pile for 400B tokens (GPT-3 hyperparameters) and compared with public checkpoints of similar size (GPT-Neo trained on the Pile, GPT-2 trained on WebText, OPT); the authors note GPT-2 perplexities are not directly comparable because of different training data. On SuperGLUE (rank classification on logits) the hybrids are stated to outperform or match the best Transformer baseline on more than half the tasks.([Section 5.1, p.9](https://arxiv.org/pdf/2212.14052v3#page=9 "We report the PPL of GPT-2 models for context, though the performance is not directly comparable since they were trained on diﬀerent data."))
- **c7** Inference speed: with the recurrent view, a 1.3B hybrid model is stated to have up to 2.4x higher generation throughput than a Transformer of similar size (A100 80GB, batch 64, prompt lengths 512-1536, 128 generated tokens; the caption says the difference is larger for longer sequences).([Section 5.1, p.9](https://arxiv.org/pdf/2212.14052v3#page=9 "The hybrid model has up to 2.4× higher throughput."))
- **c8** Generation-based evaluation caveat: when SuperGLUE answers are generated rather than rank-classified, few-shot trends match the logit results, but the hybrid and H3 models perform very poorly zero-shot on some tasks, tending to generate long irrelevant responses.([Appendix F.7, p.23](https://arxiv.org/pdf/2212.14052v3#page=23 "The trends for few-shot learning match with the logit results, but the hybrid and H3 models perform very poorly in zero-shot performance on some tasks."))
