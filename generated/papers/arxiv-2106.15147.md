- **c1** Corruption procedure: for each example, a fraction of the features is sampled uniformly at random and each of those features is replaced by a random draw from that feature's empirical marginal distribution, defined as the uniform distribution over the values the feature takes across the training dataset; both views are then passed through the encoder f and the pre-train head g.([Section 3, p.4](https://arxiv.org/pdf/2106.15147v2#page=4 "We sample some fraction of the features uniformly at random and replace each of those features by a random draw from that feature’s empirical marginal distribution,"))
- **c2** Relation to VIME (citing Yoon et al., 2020), which the authors say proposes the same corruption technique: the key differences are that SCARF pre-trains with a contrastive loss, which the authors state they show to be more effective than the denoising auto-encoder loss that partly constitutes VIME, and that after pre-training all weights including the encoder are fine-tuned using task supervision only (VIME fine-tunes only the task head).([Section 2, p.3](https://arxiv.org/pdf/2106.15147v2#page=3 "The key differences with our work is that we pre-train using a contrastive loss, which we show to be more effective than the denoising auto-encoder loss that partly constitutes VIME."))
- **c3** Datasets and splits: 69 classification datasets from the public OpenML-CC18 benchmark (72 datasets minus MNIST, Fashion-MNIST and CIFAR10); for each dataset 70%/10%/20% train/validation/test splits are formed, a different split for every trial, with all methods using the same splits. Categorical features are one-hot encoded (SCARF's marginal sampling is done before one-hot encoding).([Section 4, p.4](https://arxiv.org/pdf/2106.15147v2#page=4 "For each OpenML dataset, we form 70%/10%/20% train/validation/test splits, where a different split is generated for every trial and all methods use the same splits."))
- **c4** Fixed settings across experiments (unless specified otherwise): encoder f is a 4-layer ReLU network with hidden dimension 256, heads g and h are 2-layer ReLU networks; Adam with the default learning rate 0.001; batch size 128; early stopping with patience 3 (classification error as the fine-tuning validation metric); max 200 fine-tune and 1000 pre-train epochs; corruption rate 0.6 and temperature 1 for SCARF-based methods; all runs repeated 30 times with different splits; about one million CPU core hours in total.([Section 4, p.4](https://arxiv.org/pdf/2106.15147v2#page=4 "Unless speciﬁed otherwise, we use the following settings across all experiments."))
- **c5** Comparison method: results are summarized with a win matrix over the 69 datasets in which a 'win' or 'loss' is counted only when the means are not a statistical tie under Welch's t-test (p-value 0.05); box plots of relative improvement use only datasets where the means differ with p-value 0.20.([Section 4, p.5](https://arxiv.org/pdf/2106.15147v2#page=5 "“Beats” and “loses” are only deﬁned when the means are not a statistical tie (using Welch’s t-test with unequal variance and a p-value of 0.05)."))
- **c6** Fully labeled setting: all five pre-training techniques considered improve over no pre-training (control), SCARF outperforms the other pre-training methods with more statistically significant wins, and SCARF pre-training also boosts mixup, label smoothing, distillation and dropout; the authors say this suggests pre-training complements existing solutions and that a distinct mechanism is at play.([Section 4.1, p.7](https://arxiv.org/pdf/2106.15147v2#page=7 "We observe that SCARF generally outperforms the alternatives and adds a 1-2% relative gain across the board."))
- **c7** Label-noise setting (30% of training labels replaced by a uniformly drawn class, validation and test uncorrupted): SCARF outperforms the other pre-training methods and boosts all baselines, including label-noise methods such as Deep k-NN and the bi-tempered loss.([Section 4.2, p.7](https://arxiv.org/pdf/2106.15147v2#page=7 "Again, we see SCARF outperforms the rest and boosts all baselines by 2-3%."))
- **c8** Limited-label setting (only 25% of the training split keeps its labels; autoencoders, SCARF, self-training and tri-training use the unlabeled remainder): SCARF outperforms the other methods.([Section 4.3, p.8](https://arxiv.org/pdf/2106.15147v2#page=8 "SCARF outperforms the rest, adding a very impressive 2-4% to all baselines."))
- **c9** Ablation on corruption strategies under different feature scalings (z-score and min-max shown in the appendix figure): SCARF marginal sampling generally outperforms the alternatives; the authors note it has no hyperparameters and is invariant to feature scaling, whereas additive noise must be rescaled with the features.([Section 4.4, p.9](https://arxiv.org/pdf/2106.15147v2#page=9 "Marginal sampling is neat in that in addition to not having hyperparameters, it is invariant to scaling and preserves the “units” of each feature."))
