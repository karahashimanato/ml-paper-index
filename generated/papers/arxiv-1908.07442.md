## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Motivation and design: TabNet uses sequential attention to choose which features to reason from at each decision step; the authors state this enables interpretability and more efficient learning because learning capacity is used for the most salient features.([Abstract, p.1](https://arxiv.org/pdf/1908.07442v5#page=1 "TabNet uses sequential attention to choose which features to reason from at each decision step, enabling interpretability and more efﬁcient learning as the learning capacity is used for the most salient features."))
- **c2** Feature selection mechanism: a learnable multiplicative mask is computed by an attentive transformer from the previous step's processed features and normalized with sparsemax (citing Martins and Astudillo 2016), which the authors say was observed to be superior in performance and aligned with sparse feature selection for explainability; a prior scale with relaxation parameter gamma controls how often a feature can be reused across steps, and an entropy-form sparsity regularizer is added to the loss.([TabNet for Tabular Learning, p.3](https://arxiv.org/pdf/1908.07442v5#page=3 "Sparsemax normalization (Martins and Astudillo 2016) encourages sparsity by mapping the Euclidean projection onto the probabilistic simplex, which is observed to be superior in performance and aligned with the goal of sparse feature selection for explainability."))
- **c3** Input handling: raw numerical features are used, categorical features are mapped with trainable embeddings, and no global feature normalization is applied (only batch normalization); in the experiments categorical inputs are mapped to a single-dimensional trainable scalar and numerical columns are input without preprocessing.([TabNet for Tabular Learning, p.3](https://arxiv.org/pdf/1908.07442v5#page=3 "We do not consider any global feature normalization, but merely apply batch normalization (BN)."))
- **c4** Interpretability argument: if a mask entry is 0 the feature should have no contribution at that step; masks are interpretable as feature importance only in an approximate sense, since the coefficient would correspond to feature importance if the step function were linear, while steps are non-linear but their outputs are combined linearly. Step masks are aggregated by weighting each step with its summed ReLU decision output.([TabNet for Tabular Learning (Interpretability), p.5](https://arxiv.org/pdf/1908.07442v5#page=5 "Although each decision step employs non-linear processing, their outputs are combined later in a linear way."))
- **c5** Evidence for interpretability: on synthetic data the aggregate masks focus on the relevant features (the visualized models were trained with 10M rather than 10K samples to get sharper masks); on Mushroom, TabNet assigns 43% importance to 'Odor' while LIME, Integrated Gradients and DeepLift assign less than 30% (the latter figures cited from Ibrahim et al. 2019); on Adult the rankings are described as consistent with well-known methods.([Interpretability, p.7](https://arxiv.org/pdf/1908.07442v5#page=7 "TabNet assigns an importance score ratio of 43% for it, while other methods like LIME (Ribeiro, Singh, and Guestrin 2016), Integrated Gradients (Sundararajan, Taly, and Yan 2017) and DeepLift (Shrikumar, Greenside, and Kundaje 2017) assign less than 30% (Ibrahim et al. 2019)."))
- **c6** Evaluation protocol as stated in the appendix: for all the comparison models a hyperparameter tuning with the same number of search steps is run (per-dataset sources of baseline numbers and settings are listed in notes).([Appendix (Experiment hyperparameters), p.9](https://arxiv.org/pdf/1908.07442v5#page=9 "For all the comparison models, we run a hyperparameter tuning with the same number of search steps."))
- **c7** On the KDD datasets (described as performance-saturated), TabNet achieves very similar or slightly worse performance than XGBoost and CatBoost, which the authors describe as robust because they contain a high amount of ensembles.([Appendix (Performance on KDD datasets), p.9](https://arxiv.org/pdf/1908.07442v5#page=9 "Table 8 shows that TabNet achieves very similar or slightly worse performance than XGBoost and CatBoost, that are known to be robust as they contain high amount of ensembles."))
- **c8** Self-supervised pre-training (masked feature-column prediction with a decoder) is reported to significantly improve supervised accuracy on Higgs (TabNet-M, mean and std over 15 runs, 1k/10k/100k labeled samples), especially when the unlabeled dataset is much larger than the labeled one, and to speed convergence.([Self-supervised learning, p.7](https://arxiv.org/pdf/1908.07442v5#page=7 "Table 7 shows that unsupervised pre-training signiﬁcantly improves performance on the supervised classiﬁcation task, especially in the regime where the unlabeled dataset is much larger than the labeled dataset."))
- **c9** Hyperparameter sensitivity: the paper states TabNet is not very sensitive to most hyperparameters, but the Forest Cover ablation reports that high performance needs capacity adjusted to the dataset and that increasing units or decision steps beyond some value causes optimization issues without performance benefit.([Appendix (Ablation studies), p.10](https://arxiv.org/pdf/1908.07442v5#page=10 "On the other hand, increasing these parameters beyond some value causes optimization issues and do not yield performance beneﬁts."))
- **c10** Mask and prior scale: M[i] = sparsemax(P[i-1] . h_i(a[i-1])) is applied multiplicatively to the features (M[i] . f), each row of M[i] sums to 1, and the prior scale P[i] = prod_{j=1}^{i} (gamma - M[j]) records how much each feature has been used in previous steps; gamma = 1 enforces a feature to be used at only one step, and larger gamma allows more reuse.([TabNet for Tabular Learning, p.3](https://arxiv.org/pdf/1908.07442v5#page=3 "is the prior scale term, denoting how much a particular feature"))
