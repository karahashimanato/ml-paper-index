## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Main critique: the authors claim that ECE has numerous pathologies and that recent calibration methods shown to recalibrate models according to ECE cannot be properly evaluated via ECE.([Introduction, p.2](https://arxiv.org/pdf/1904.01685v2#page=2 "In this paper, we show that ECE has numerous pathologies, and that recent calibration methods, which have been shown to successfully recalibrate models according to ECE, cannot be properly evaluated via ECE."))
- **c2** ECE as framed by Naeini et al. (2015) leaves ambiguity in the binning implementation and in how to handle multiple classes; the paper's ECE implementation follows Guo et al. (2017): equally spaced bins on [0, 1] and only the maximum (predicted-class) probability per data point.([Background & Related Work (Expected Calibration Error), p.2](https://arxiv.org/pdf/1904.01685v2#page=2 "ECE as framed in Naeini et al. (2015) leaves ambiguity in both its binning implementation and how to compute calibration for multiple classes."))
- **c3** Choosing the number of bins is a bias-variance tradeoff: more bins give a more granular (low-bias) measure but higher variance per bin as bins become sparsely populated; because of sharpness (confident predictions), some bins hold many more points than others, which compounds the problem.([Issues With Calibration Metrics (Bias-Variance Tradeoff), p.4](https://arxiv.org/pdf/1904.01685v2#page=4 "Selecting the number of bins has a bias-variance tradeoff as it determines how many data points fall into each bin and therefore the quality of the estimate of calibration from that bin’s range."))
- **c4** Static binning allows cancellation: overconfident and underconfident predictions in the same bin can give near-zero calibration error. The authors hedge that these effects may not always be extreme enough to bring a very miscalibrated model to zero, but say it can be difficult to judge whether a measured improvement is real or due to cancellation (an appendix code example constructs a near-zero ECE for an extremely miscalibrated softmax).([Issues With Calibration Metrics (Pathologies in Static Binning Schemes), p.4](https://arxiv.org/pdf/1904.01685v2#page=4 "Metrics that depend on static binning schemes like ECE suffer from issues where you can get near 0 calibration error due to overconﬁdent and underconﬁdent predictions overlapping in the same bin."))
- **c5** ECE focuses only on the maximum probability per data point; SCE extends it to every class probability (binned separately per class, then averaged over classes). The authors state that, unlike ECE, SCE is guaranteed to be zero if and only if the model is calibrated, under the assumption of infinite data and infinite bins.([Analyzing The Space of Calibration with General Calibration Error (Maximum Probability), p.5](https://arxiv.org/pdf/1904.01685v2#page=5 "Unlike ECE, assuming inﬁnite data and inﬁnite bins, SCE is guaranteed to be zero if only if the model is calibrated."))
- **c6** Class conditionality: histogram binning optimizes directly for a notion of calibration error and is therefore measured overconfidently by a metric that matches its assumptions; on CIFAR-10 the ECE of histogram binning was one-third of the class-conditional ECE (and one-fifth on ImageNet, after controlling with the uncalibrated score). Histogram-binning probabilities come from average accuracy on the validation dataset.([Experiments (Class Conditionality), p.6](https://arxiv.org/pdf/1904.01685v2#page=6 "We ﬁnd that on CIFAR 10 the ECE estimate of the calibration error is one-third that of the class conditional variant, which is the same as ECE in all respects but class conditionality (Table 1)."))
- **c7** Metric choice changes conclusions: ranking 8 recalibration techniques (histogram binning variants, isotonic regression, temperature scaling, ECE-optimized temperature scaling, vector/matrix scaling, neural network scaling) on CIFAR-10 predictions of a Wide ResNet with 32 metric variants gave dramatically different orderings.([Recalibration Experiments, p.7](https://arxiv.org/pdf/1904.01685v2#page=7 "This demonstrates that varying the properties of the calibration error metric can lead to different conclusions about which model has the best calibration."))
- **c8** Sensitivity to the number of bins (10, 20, 30, 40, 50) was measured by mean rank correlation over recalibration techniques on a Wide ResNet on CIFAR-10: adaptive-binning metrics had 0.5927 versus 0.3677 for even binning, which leads the authors to recommend adaptive binning; they also recommend class conditioning and the L2 norm.([Experiments (Sensitivity to the Number of Bins Hyperparameter), p.7](https://arxiv.org/pdf/1904.01685v2#page=7 "This result leads us to recommend adapative binning as a method to improve rank order robustness to the number of bins hyperparameter."))
- **c9** Limitation acknowledged: adaptive metrics can create excessively large ranges where outputs are sparse; a very large number of ranges would recover granularity at the cost of interpretability and higher within-range variance.([Discussion (Criticisms & Limitations), p.8](https://arxiv.org/pdf/1904.01685v2#page=8 "Adaptive calibration metrics can create excessively large ranges if there is very sparse output in a region."))
