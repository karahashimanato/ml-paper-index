## この記事の読み方

「このモデルはなぜこの予測をしたのか」に答える手法を、14本の論文から整理する。
扱うのは主に次の2つである。

- **事後説明**: 学習済みのモデルに後から説明を付ける(LIME、SHAP、Integrated Gradients、saliency map、attention の重みなど)。
- **解釈可能なモデル**: モデルの構造そのものが説明になる(加法モデル、ルールリストなど)。

この記事は「どの手法が一番良いか」を決めるものではない。説明の良さには**唯一の正解がない**ことが多く、論文ごとに「良い説明」の定義と測り方が違う。
そのため、各手法が**何を前提にしているか**と、**どう評価されたか**を中心に書く。

## 各手法が置いている前提

事後説明の多くは、**明示されにくい前提**の上に立っている。前提が崩れる場面では、説明はモデルの挙動を正しく表さない。

- **SHAP**: 実用的な推定法は、条件付き期待値の計算を簡単にするため、特徴量の独立性やモデルの線形性を仮定しうる [arxiv-1705.07874#c3](https://arxiv.org/pdf/1705.07874v2#page=5 "When using these methods, feature independence and model linearity are two optional assumptions simplifying the computation of the expected values")。Deep SHAP は DeepLIFT に基づき、同じく独立性と線形性を仮定した近似である [arxiv-1705.07874#c4](https://arxiv.org/pdf/1705.07874v2#page=7 "If we interpret the reference value in Equation 3 as representing E[x] in Equation 12, then DeepLIFT approximates SHAP values assuming that the input features are independent of one another and the deep model is linear.")。
- **LIME**: 疎な線形モデルで近似するため、局所的にも強く非線形なモデルには忠実な説明がありえない [arxiv-1602.04938#c2](https://arxiv.org/pdf/1602.04938v3#page=4 "Second, our choice of G (sparse linear models) means that if the underlying model is highly non-linear even in the locality of the prediction, there may not be a faithful explanation.")。
- **Integrated Gradients**: 寄与は**基準点(ベースライン)に対する相対値**である。著者は、信号がまったくない状態(黒い画像、ゼロの埋め込み)を基準点にすることを勧めている [arxiv-1703.01365#c3](https://arxiv.org/pdf/1703.01365v2#page=5 "So we would additionally like the baseline to convey a complete absence of signal, so that the features that are apparent from the attributions are properties only of the input, and not of the baseline.")。
- **Shapley 値の「価値関数」の選択**: 特徴量を取り除いた状態をどう定義するかで、条件付き(観測的)と介入的の2通りがある。
  - 条件付きは特徴量間の依存関係を別途モデル化する必要があり、介入的は分布の外のデータでモデルを評価することになる [arxiv-2002.11097#c2](https://arxiv.org/pdf/2002.11097v2#page=3 "Unfortunately, the decision between the two types of value functions is a catch-22.")。
  - 線形モデルで観測的な Shapley 値を計算するときは、入力が多変量正規分布であると仮定する [arxiv-2006.16234#c2](https://arxiv.org/pdf/2006.16234v1#page=2 "Estimating this conditional expectation is hard in general, so we assume the inputs x ∼N(µ, Σ) are multivariate normal.")。
  - 著者は、現状で寄与の計算に最も良いのは摂動する特徴量が独立な場合で、そのとき両者は一致するとしている [arxiv-2006.16234#c7](https://arxiv.org/pdf/2006.16234v1#page=6 "Currently, the best case for feature attribution is when the features that being perturbed are independent to start with.")。
- **TreeExplainer**: 既定では木をたどって条件付き期待値を計算し、特徴量の独立性を仮定するオプションもある [arxiv-1905.04610#c3](https://arxiv.org/pdf/1905.04610v1#page=6 "By default, TreeExplainer computes conditional expectations using tree traversal, but it also provides an option that enforces feature independence and supports explaining a model’s loss function (Methods 10).")。

公理による正当化もある。SHAP は、加法的な寄与の手法の中で局所的な正確さ・一貫性などを満たすのは Shapley 値だけだとする [arxiv-1705.07874#c2](https://arxiv.org/pdf/1705.07874v2#page=4 "This result implies that methods not based on Shapley values violate local accuracy and/or consistency (methods in Section 2 already respect missingness).") [arxiv-1905.04610#c2](https://arxiv.org/pdf/1905.04610v1#page=5 "results from game theory imply the Shapley values are the only way to satisfy three important properties: local accuracy, consistency, and missingness (Methods 9)")。
Integrated Gradients は別の2つの公理(感度、実装不変性)を立て、既存の多くの手法がどちらかを満たさないとした [arxiv-1703.01365#c1](https://arxiv.org/pdf/1703.01365v2#page=1 "We show that they are not satisfied by most known attribution methods, which we consider to be a fundamental weakness of those methods.")。
**公理だけでは「正しい」手法は一つに決まらない**点に注意が要る(この記事の整理)。Integrated Gradients の著者は、複数の経路での平均を許せば Shapley 値に基づく方法(Shapley-Shubik)も公理を満たすが、寄与は Integrated Gradients と異なると述べる。簡単な例では、どちらの結果を好むかはやや主観的だとしている [arxiv-1703.01365#c5](https://arxiv.org/pdf/1703.01365v2#page=5 "This method yields attributions that are different from integrated gradients.")。

### 評価方法そのものの食い違い: 特徴量を消したあとに再学習するか

重要な特徴量を消して性能の低下を見る評価には、立場の食い違いがある(両者を対立として並べるのはこの記事の整理)。

- **再学習すべき**: ROAR は、再学習しないと、精度の低下が「重要な特徴を消したから」なのか「消したことで分布の外のデータになったから」なのかを区別できないと指摘する [arxiv-1806.10758#c2](https://arxiv.org/pdf/1806.10758v3#page=1 "Without re-training,it is unclear whether the degradation in model performance comes from the distribution shift or because the features that were removed are truly informative [10, 12].")。Integrated Gradients の著者も、摂動した画像が不自然で、学習中に見たことのない入力のために出力が下がる可能性を挙げ、経験的なベンチマークではなく公理による方法を採った [arxiv-1703.01365#c4](https://arxiv.org/pdf/1703.01365v2#page=3 "However, the images resulting from pixel perturbation could be unnatural, and it could be that the scores drop simply because the network has never seen anything like it in training.")。
- **再学習すべきでない**: TreeExplainer の著者は、再学習に基づく指標は場合によって誤解を招くとして、意図的に除外した [arxiv-1905.04610#c5](https://arxiv.org/pdf/1905.04610v1#page=24 "After extensive consideration, we did not include metrics based on retraining the original model since, while informative, these can produce misleading results in certain situations.")。ROAR 自身も、評価に使う再学習後のモデルは説明したモデルとは別物だと認めている [arxiv-1806.10758#c6](https://arxiv.org/pdf/1806.10758v3#page=4 "For one, while the architecture is the same, the model used during evaluation is not the same as the model on which the feature importance estimates were originally obtained.")。冗長な特徴量があると、全部消すまで精度が下がらないこともある [arxiv-1806.10758#c7](https://arxiv.org/pdf/1806.10758v3#page=5 "This plot also shows the limitation of ROAR, an accuracy decrease might not happen until a complete set of fully redundant features is removed.")。

SHAP の原論文の MNIST 実験は画素を隠して評価しており、再学習の記述はない [arxiv-1705.07874#c7](https://arxiv.org/pdf/1705.07874v2#page=9 "To match [7], we masked 20% of the pixels chosen to switch the predicted class from 8 to 3 according to the feature attribution given by each method.")。どちらの立場の評価かで、同じ手法の見え方が変わりうる。

## 報告されている失敗のパターン

### 見た目がもっともらしくても、モデルを反映していない

- Sanity Checks では、Guided BackProp と Guided GradCAM が上位層の重みに対して不変で、検査に通らなかった。勾配そのものと GradCAM は通った [arxiv-1810.03292#c4](https://arxiv.org/pdf/1810.03292v3#page=3 "Of the methods tested, Gradients & GradCAM pass the sanity checks, while Guided BackProp & Guided GradCAM are invariant to higher layer parameters; hence, fail.")。
- 目で見て確かめるだけでは、構造が似ていて重みがまったく違うネットワークを区別できない [arxiv-1810.03292#c5](https://arxiv.org/pdf/1810.03292v3#page=5 "The observed visual perception versus ranking dichotomy indicates that naive visual inspection of the masks, in this setting, does not distinguish networks of similar structure but widely differing parameters.")。
- 勾配の代わりにランダムなベクトルを掛ける実験から、入力×勾配に近い手法(ε-LRP、DeepLift、Integrated Gradients)は、勾配が雑音的に見えるときほぼ入力そのものを返すと結論している [arxiv-1810.03292#c6](https://arxiv.org/pdf/1810.03292v3#page=9 "This experiment indicates that methods that approximate the “input-times-gradient” mostly return the input, in cases where the gradients look visually noisy as they tend to do.")。
- Rudin は、saliency map がクラスによらずほぼ同じに見えうること、正解のクラスの説明だけを見せるのは誤解を招くことを指摘する [arxiv-1811.10154#c4](https://arxiv.org/pdf/1811.10154v3#page=4 "Demonstrating a method using explanations only for the correct class is misleading.")。

### ランダムな説明と区別できない

ROAR では、勾配、Integrated Gradients、Guided BackProp が、ランダムに重要度を割り当てた場合と同等以下だった [arxiv-1806.10758#c4](https://arxiv.org/pdf/1806.10758v3#page=9 "Surprisingly, we find that the commonly used base estimators, Gradients, Integrated Gradients and Guided BackProp are worse or on par with a random assignment of importance.")。
VarGrad や SmoothGrad-Squared は元の推定を大きく改善したが、SmoothGrad のようなアンサンブルは計算量が多いのに単一の推定を改善せず、悪化する場合もあった [arxiv-1806.10758#c5](https://arxiv.org/pdf/1806.10758v3#page=9 "However, we do find that VarGrad and SmoothGrad-Squared strongly improve the quality of these methods and far outperform a random guess.")。

### 手法どうしで答えが違う

- 説明手法どうしは**しばしば一致せず**、実務者はその不一致を場当たり的な判断で解消している [arxiv-2202.01602#c4](https://arxiv.org/pdf/2202.01602v6#page=1 "Our results indicate that (1) state-of-the-art explanation methods often disagree in terms of the explanations they output, and (2) machine learning practitioners often employ ad hoc heuristics when resolving such disagreements.")。
- 不一致はモデルが複雑になるほど大きくなりうる [arxiv-2202.01602#c5](https://arxiv.org/pdf/2202.01602v6#page=8 "These trends suggest that disagreement among explanation methods may increase with model complexity.")。測り方によって不一致の程度も変わる [arxiv-2202.01602#c6](https://arxiv.org/pdf/2202.01602v6#page=15 "Finally, the extent of explanation disagreement would also depend on the specific metric being used to measure the disagreement.")。
- SHAP の原論文も、LIME の値が SHAP の値と大きく異なりうることを示している [arxiv-1705.07874#c5](https://arxiv.org/pdf/1705.07874v2#page=8 "Comparing Shapley sampling, SHAP, and LIME on both dense and sparse decision tree models illustrates both the improved sample efficiency of Kernel SHAP and that values from LIME can differ significantly from SHAP values that satisfy local accuracy and consistency.")。

### 意図的に欺ける

- 偏ったモデルの偏りを、LIME や SHAP の説明から隠す仕組みが提案された [arxiv-1911.02508#c1](https://arxiv.org/pdf/1911.02508v2#page=1 "Specifically, we propose a novel scaffolding technique that effectively hides the biases of any given classifier by allowing an adversarial entity to craft an arbitrary desired explanation.")。LIME 式の摂動サンプルは実データと分布が異なり、見分けるのは難しくないため、摂動に強く頼る手法は操作されうる [arxiv-1911.02508#c2](https://arxiv.org/pdf/1911.02508v2#page=3 "This result indicates that detecting whether a data point is a result of a perturbation or not is not a challenging task, and thus approaches that rely heavily on these perturbations, such as LIME, can be gamed.")。
- 摂動点と実データをそれなりの精度で見分けられれば、この攻撃は成立する [arxiv-1911.02508#c6](https://arxiv.org/pdf/1911.02508v2#page=6 "These results indicate that our attacks are effective as long as it is possible to differentiate between perturbed instances and input data points with a reasonable accuracy.")。
- 刑事司法と与信のデータで、LIME のほうが SHAP より欺きやすかった [arxiv-1911.02508#c7](https://arxiv.org/pdf/1911.02508v2#page=7 "Extensive experimentation with real world data from criminal justice and credit scoring domains demonstrates that our approach is effective at generating adversarial classifiers that can fool post hoc explanation techniques, finding that LIME is more vulnerable than SHAP.")。SHAP に対しては、2つの無相関な特徴量を使う攻撃で、敏感な特徴量を順位の1位から外すことがあまりうまくいかず、著者はその理由を局所的な正確さの性質に帰している [arxiv-1911.02508#c5](https://arxiv.org/pdf/1911.02508v2#page=5 "This is due to SHAP’s local accuracy property that ensures that feature attributions must add up to the difference between a given prediction and the average prediction for the background distribution.")。

### Shapley 値に基づく説明の数学的な問題

- 条件付きの価値関数では、ある特徴量の**冗長なコピー**を加えるだけで、モデルは実質同じなのに他の特徴量の寄与が変わる [arxiv-2002.11097#c3](https://arxiv.org/pdf/2002.11097v2#page=4 "The relative apparent importances of A and B thus depend on whether C is considered to be a third feature, even though the two functions are effectively the same.")。
- 介入的な価値関数は分布の外のサンプルでの評価に頼るため、モデルがデータから学んだこととは無関係な性質に敏感になる [arxiv-2002.11097#c4](https://arxiv.org/pdf/2002.11097v2#page=5 "Methods which use an interventional value function fundamentally rely on evaluating a model on out-of-distribution samples (Figure 1).")。
- 独立で平均0の特徴量の積で表される関数では、値によらずすべての特徴量が同じ Shapley 値を受け取る [arxiv-2002.11097#c5](https://arxiv.org/pdf/2002.11097v2#page=6 "This property will, in fact, hold for all multiplicative functions of independently distributed, zero-centered data.")。
- 寄与が大きいからといって、その特徴量を変えれば結果が望ましく変わるとは限らない [arxiv-2002.11097#c6](https://arxiv.org/pdf/2002.11097v2#page=8 "Further, observing that a certain feature carries a large influence over the model does not necessarily imply that changing that feature (even significantly) will change the outcome favorably.")。
- 観測的な Shapley 値では、**モデルが使っていない特徴量**にも、相関を通じて重要度が付きうる(NHANES の死亡データと線形モデルの例) [arxiv-2006.16234#c3](https://arxiv.org/pdf/2006.16234v1#page=3 "This implies that even though BMI is not included in the model, the correlation between BMI and other features makes BMI important under observational Shapley values.")。

## 続いている論争

### 1. attention の重みは説明になるか

- **否定側**(Jain & Wallace): 自然言語処理の複数のタスクで、attention の重みは勾配に基づく重要度としばしば相関せず、まったく違う attention でも同じ予測になりうる [arxiv-1902.10186#c1](https://arxiv.org/pdf/1902.10186v3#page=1 "learned attention weights are frequently uncorrelated with gradient-based measures of feature importance, and one can identify very different attention distributions that nonetheless yield equivalent predictions")。BiLSTM と標準的な attention では、説明に求められる2つの性質(重要度との相関、別の attention なら予測が変わること)がどちらも一貫しては観察されなかった [arxiv-1902.10186#c2](https://arxiv.org/pdf/1902.10186v3#page=1 "(i) Attention weights should correlate with feature importance measures (e.g., gradient-based measures); (ii) Alternative (or counterfactual) attention weight configurations ought to yield corresponding changes in prediction") [arxiv-1902.10186#c3](https://arxiv.org/pdf/1902.10186v3#page=1 "We report that neither property is consistently observed by a BiLSTM with a standard attention mechanism in the context of text classification, question answering (QA), and Natural Language Inference (NLI) tasks.")。著者自身、扱った attention の種類は限られていると述べている [arxiv-1902.10186#c7](https://arxiv.org/pdf/1902.10186v3#page=11 "An additional limitation is that we have only considered a handful of attention variants, selected to reflect common module architectures for the respective tasks included in our analysis.")。
- **反論側**(Wiegreffe & Pinter): 上の研究は attention をそれを計算するパラメータから切り離して扱っている [arxiv-1908.04626#c2](https://arxiv.org/pdf/1908.04626v2#page=3 "Jain and Wallace detach the attention distribution and output layer of their pretrained network from the parameters that compute them (see Figure 1), treating each attention score as a standalone unit independent of the model.")。説明になるかどうかは「説明」の定義(もっともらしさか、忠実さか)に依存する [arxiv-1908.04626#c5](https://arxiv.org/pdf/1908.04626v2#page=9 "Whether or not attention is explanation depends on the definition of explainability one is looking for: plausible or faithful explanations (or both).")。ただし、一部のタスクで敵対的な attention が見つかることには同意している [arxiv-1908.04626#c6](https://arxiv.org/pdf/1908.04626v2#page=9 "However, we have confirmed that adversarial distributions can be found for LSTM models in some classification tasks, as originally hypothesized by Jain and Wallace.")。また、一部のデータセットでは attention が予測をほとんど改善していないように見え、検証の題材として有用でないと指摘した [arxiv-1908.04626#c3](https://arxiv.org/pdf/1908.04626v2#page=5 "We conclude that these datasets, notably AG NEWS and 20 NEWSGROUPS, are not useful test cases for the debated question: attention is not explanation if you don’t need it.")。

表データのモデルでも attention を重要度として使う例がある。FT-Transformer の著者は、attention マップの平均が Integrated Gradients と同程度の重要度の順位を、はるかに低いコストで与えたと報告している [arxiv-2106.11959#c15](https://arxiv.org/pdf/2106.11959v5#page=10 "we conclude that the simple averaging of attention maps can be a good choice in terms of cost-effectiveness.")。
TabPFN v2 の attention の重みを、ラベルなしで特徴量の重要度として読む研究もある [arxiv-2608.10522#c3](https://arxiv.org/pdf/2608.10522v1#page=4 "These pseudo-labels adapt a frozen tabular foundation model[12].")。
ただし、上の論争と ROAR の結果(画像分類での結果) [arxiv-1806.10758#c4](https://arxiv.org/pdf/1806.10758v3#page=9 "Surprisingly, we find that the commonly used base estimators, Gradients, Integrated Gradients and Guided BackProp are worse or on par with a random assignment of importance.") を踏まえると、**別の説明手法と一致することは、どちらもモデルに忠実であることの証明にはならない**(この記事の整理。Jain & Wallace も、比較に使った勾配などの指標を正解とはみなしていない [arxiv-1902.10186#c6](https://arxiv.org/pdf/1902.10186v3#page=11 "We do not intend to imply that such alternative measures are necessarily ideal or that they should be considered ‘ground truth’."))。

### 2. Shapley 値の価値関数はどちらを使うべきか

- Kumar らは、条件付きと介入的のどちらを選んでも問題が残る「キャッチ22」だとし [arxiv-2002.11097#c2](https://arxiv.org/pdf/2002.11097v2#page=3 "Unfortunately, the decision between the two types of value functions is a catch-22.")、問題の緩和には因果的な推論などの複雑さが必要になるとする [arxiv-2002.11097#c1](https://arxiv.org/pdf/2002.11097v2#page=1 "We show that mathematical problems arise when Shapley values are used for feature importance, and that the solutions to mitigate these necessarily induce further complexity, such as the need for causal reasoning.")。
- Chen らはこれに名指しで応答し、両者は**適切な文脈で使えばそれぞれ意味がある**と主張した [arxiv-2006.16234#c1](https://arxiv.org/pdf/2006.16234v1#page=2 "in this paper, we argue that rather than representing some critical flaw in using the Shapley value for feature attribution, each approach is meaningful when applied in the proper context")。モデルの挙動を知りたい場合(融資の例)は介入的のほうが良く [arxiv-2006.16234#c5](https://arxiv.org/pdf/2006.16234v1#page=5 "We find that using the interventional conditional expectation leads to significantly better results than the observational conditional expectation (Figure 3).")、データの背後の因果を知りたい場合(遺伝子の例、Lasso モデル)は観測的のほうが正解の因果遺伝子を多く拾った [arxiv-2006.16234#c6](https://arxiv.org/pdf/2006.16234v1#page=5 "To create an experimental setting where we have access to the ground truth, we take the real RNA-seq data and simulate a drug response label as a function of 40 randomly selected causal genes (out of 1000 total genes).")。

Chen らの論文の著者には SHAP・TreeExplainer の著者(Lundberg、Lee)が含まれる(下の「評価者の独立性」を参照)。

### 3. ブラックボックスを説明するか、最初から解釈可能なモデルを作るか

- Rudin は、高リスクな意思決定では、ブラックボックスを説明しようとすること自体が悪い慣行を温存し、社会に深刻な害を及ぼしうると主張する [arxiv-1811.10154#c1](https://arxiv.org/pdf/1811.10154v3#page=1 "trying to explain black box models, rather than creating models that are interpretable in the first place, is likely to perpetuate bad practices and can potentially cause catastrophic harm to society")。
  - 事後説明は元のモデルに完全には忠実でありえない(完全に忠実なら、それはモデルそのものである) [arxiv-1811.10154#c3](https://arxiv.org/pdf/1811.10154v3#page=3 "If the explanation was completely faithful to what the original model computes, the explanation would equal the original model, and one would not need the original model in the first place, only the explanation.")。
  - 構造化された意味のある特徴量のデータでは、前処理をすれば、複雑な分類器と単純な分類器の性能差は有意でないことが多いとする [arxiv-1811.10154#c2](https://arxiv.org/pdf/1811.10154v3#page=2 "there is often no significant difference in performance between more complex classifiers (deep neural networks, boosted decision trees, random forests) and much simpler classifiers (logistic regression, decision lists) after preprocessing")。
  - 同程度に正確なモデルが多数ある場合、その中に解釈可能なモデルが含まれることが多い、という「羅生門集合」の議論 [arxiv-1811.10154#c6](https://arxiv.org/pdf/1811.10154v3#page=14 "Because this set of accurate models is large, it often contains at least one model that is interpretable.")。
  - ただし、ブラックボックスが必要な分野がありうることは認めている [arxiv-1811.10154#c7](https://arxiv.org/pdf/1811.10154v3#page=3 "It could be possible that there are application domains where a complete black box is required for a high stakes decision.")。
- Neural Additive Models はこの立場に近く(この記事の整理)、特徴量ごとの形状関数の図は近似的な説明ではなく、モデルの計算そのものだとする [arxiv-2004.13912#c2](https://arxiv.org/pdf/2004.13912v2#page=4 "Please note these shape function plots are not just an explanation but an exact description of how NAMs compute a prediction.")。Explainable Boosting Machine と同程度の性能を報告している [arxiv-2004.13912#c4](https://arxiv.org/pdf/2004.13912v2#page=6 "NAMs achieve comparable performance to EBMs on both classification and regression datasets, making them a competitive alternative to EBMs.")。
  - ただし比較対象の EBM には先行研究で指定された設定をそのまま使っている [arxiv-2004.13912#c6](https://arxiv.org/pdf/2004.13912v2#page=18 "We use the open-source implementation [26] with the parameters specified by prior work [5] for a fair comparison.")。一方 NAM 自身はベイズ最適化で調整している [arxiv-2004.13912#c5](https://arxiv.org/pdf/2004.13912v2#page=18 "For computational efficiency, we tune these hyperparameters using Bayesian optimization [11, 39] based on cross-validation performance with a single train-validation split for each fold.")。また、特徴量どうしの交互作用は扱っていない [arxiv-2004.13912#c7](https://arxiv.org/pdf/2004.13912v2#page=9 "We don’t consider such interactions to keep the paper focused on additive modeling with neural nets.")。

表データで「単純なモデルでも十分なことが多い」かどうかは、[表データの記事](../tasks/tabular-gbdt-vs-deep-learning.md)で扱っている GBDT と深層学習の比較とも関係する。そちらでは、差の大きさが評価条件に強く依存することを示している。

## 評価者の独立性

この分野では、**手法の提案者が評価方法も設計している**例が目立つ。

- TreeExplainer の21の評価指標は、SHAP の著者(Lundberg、Lee)を含む著者らが自ら設計したもので、その指標で自分たちの手法を評価している [arxiv-1905.04610#c4](https://arxiv.org/pdf/1905.04610v1#page=6 "We designed 21 metrics to comprehensively evaluate the performance of local explanation methods, and applied these metrics to eight different explanation methods across three different model types and three datasets (Methods 11).")。価値関数の論争で応答した Chen らの論文 [arxiv-2006.16234#c1](https://arxiv.org/pdf/2006.16234v1#page=2 "in this paper, we argue that rather than representing some critical flaw in using the Shapley value for feature attribution, each approach is meaningful when applied in the proper context") も Lundberg と Lee を著者に含む。
- LIME の著者の1人(Singh)は、LIME と SHAP を欺く攻撃の論文の著者でもある。この場合は、自分の手法の弱点を示す側に回っている。
- Sanity Checks と ROAR は著者の1人(Been Kim)が共通している。PDF の所属表記では、この2本と Integrated Gradients のいずれにも Google の研究者が著者に含まれる。Integrated Gradients が両方の論文で弱点を指摘されたこと [arxiv-1806.10758#c4](https://arxiv.org/pdf/1806.10758v3#page=9 "Surprisingly, we find that the commonly used base estimators, Gradients, Integrated Gradients and Guided BackProp are worse or on par with a random assignment of importance.") [arxiv-1810.03292#c6](https://arxiv.org/pdf/1810.03292v3#page=9 "This experiment indicates that methods that approximate the “input-times-gradient” mostly return the input, in cases where the gradients look visually noisy as they tend to do.") は、同じ組織の研究者による批判である(独立した第三者による確認ではない)。
- 人による評価には、Mechanical Turk の利用者によるものがある(LIME では機械学習の専門家ではない参加者) [arxiv-1602.04938#c6](https://arxiv.org/pdf/1602.04938v3#page=7 "We recruit human subjects on Amazon Mechanical Turk – by no means machine learning experts, but instead people with basic knowledge about religion.") [arxiv-1705.07874#c6](https://arxiv.org/pdf/1705.07874v2#page=8 "Our testing assumes that good model explanations should be consistent with explanations from humans who understand that model.")。Kumar らが引用する研究では、SHAP が利用者による予測の正誤の判断に役立った証拠は見つからなかった [arxiv-2002.11097#c7](https://arxiv.org/pdf/2002.11097v2#page=9 "Weerts et al. (2019), for instance, conducted a human-grounded evaluation of SHAP and did not find evidence that it helped users assess the correctness of predictions.")。

## このリポジトリの他のテーマとの関係

- **表データ**: TreeSHAP は応用研究でも使われている。たとえば PISA 2022 のデータで、国ごとの LightGBM の予測要因を TreeSHAP の順位で比べた研究がある [doi-10.3389_fpsyg.2026.1875261#c1](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2026.1875261/pdf#page=1 "Per-economy LightGBM models and TreeSHAP rankings estimated relative predictive salience.")。この研究では、SHAP 値を検証用データだけでなく標本全体で集計しており、著者自身が、順位が当てはめた構造を反映している可能性を限界に挙げている [doi-10.3389_fpsyg.2026.1875261#c6](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2026.1875261/pdf#page=17 "SHAP values were summarized across the entire per-economy sample rather than the test split alone, so the rankings may partly reflect sample-internal fitted structure")。土石流の予測で TabPFN を含む多数のモデルを比べた研究 [arxiv-2608.05265#c1](https://arxiv.org/pdf/2608.05265v1#page=1 "Using basin-scale observations of post-wildfire debris-flow events across the western United States, we compare 15 models, including a new foundation model, the Tabular Prior-Data Fitted Network (TabPFN).") のように、モデルの比較と寄与の分析を同じ論文で行う応用研究もある。ただし、このリポジトリのカードはその比較の手順を記録したもので、説明手法の妥当性を評価したものではない。
- **時系列の異常検知**: サーベイは、研究が検出精度に偏り、診断に必要な解釈可能性が軽視されていると指摘する [arxiv-2211.05244#c5](https://arxiv.org/pdf/2211.05244v3#page=28 "anomaly detection research focuses primarily on detection precision, failing to address the issue of interpretability.")。2026年のベンチマーク SHAD は、既存のベンチマークは主に検出精度を扱い、空間的な説明可能性を評価するものは少なく、人が理解できる解釈に十分な意味的注釈を持つものはないとする [arxiv-2610.01168#c1](https://arxiv.org/pdf/2610.01168v1#page=1 "One of the main reasons for this gap is that current benchmarks primarily focus on detection accuracy, and only few of them evaluate spatial explainability.")。SHAD 上の説明は既存の時系列異常検知の手法では解決できず、凍結した(追加学習なしの)LLM は異常を正しく解釈できなかった [arxiv-2610.01168#c4](https://arxiv.org/pdf/2610.01168v1#page=10 "(ii) Explanability on SHAD cannot be natively solved with existing TSAD methods, and (iii) frozen LLMs are not able to provide correct interpretations of anomalies.")。

## 現時点での整理

- **説明の「正解」はほとんどの場面で存在しない**。そのため、評価は公理、人の判断、手法どうしの一致、特徴量を消したときの性能変化などで代用されている。どの代用を採るかで、同じ手法の評価が変わる(再学習の有無の対立を参照)。
- **見た目のもっともらしさは忠実さの証拠にならない**。重みをランダムにしても変わらない手法があり [arxiv-1810.03292#c4](https://arxiv.org/pdf/1810.03292v3#page=3 "Of the methods tested, Gradients & GradCAM pass the sanity checks, while Guided BackProp & Guided GradCAM are invariant to higher layer parameters; hence, fail.")、目視では区別できない [arxiv-1810.03292#c5](https://arxiv.org/pdf/1810.03292v3#page=5 "The observed visual perception versus ranking dichotomy indicates that naive visual inspection of the masks, in this setting, does not distinguish networks of similar structure but widely differing parameters.")。
- **手法どうしの一致は、どちらかが正しいことを意味しない**。そもそも手法どうしはしばしば一致しない [arxiv-2202.01602#c4](https://arxiv.org/pdf/2202.01602v6#page=1 "Our results indicate that (1) state-of-the-art explanation methods often disagree in terms of the explanations they output, and (2) machine learning practitioners often employ ad hoc heuristics when resolving such disagreements.")。
- **前提を確認する**: 特徴量が相関しているデータでは、Shapley 値の価値関数の選択で説明が変わる [arxiv-2002.11097#c2](https://arxiv.org/pdf/2002.11097v2#page=3 "Unfortunately, the decision between the two types of value functions is a catch-22.") [arxiv-2006.16234#c3](https://arxiv.org/pdf/2006.16234v1#page=3 "This implies that even though BMI is not included in the model, the correlation between BMI and other features makes BMI important under observational Shapley values.")。「モデルの挙動を知りたい」のか「データの構造を知りたい」のかを先に決める必要がある [arxiv-2006.16234#c1](https://arxiv.org/pdf/2006.16234v1#page=2 "in this paper, we argue that rather than representing some critical flaw in using the Shapley value for feature attribution, each approach is meaningful when applied in the proper context")。
- **説明は操作されうる**。外部の監査に事後説明を使う場合は、摂動を検知して振る舞いを変えるモデルがありうることを考慮する [arxiv-1911.02508#c1](https://arxiv.org/pdf/1911.02508v2#page=1 "Specifically, we propose a novel scaffolding technique that effectively hides the biases of any given classifier by allowing an adversarial entity to craft an arbitrary desired explanation.") [arxiv-1911.02508#c6](https://arxiv.org/pdf/1911.02508v2#page=6 "These results indicate that our attacks are effective as long as it is possible to differentiate between perturbed instances and input data points with a reasonable accuracy.")。
- **高リスクな場面では、解釈可能なモデルが選択肢になる** [arxiv-1811.10154#c1](https://arxiv.org/pdf/1811.10154v3#page=1 "trying to explain black box models, rather than creating models that are interpretable in the first place, is likely to perpetuate bad practices and can potentially cause catastrophic harm to society")。ただし、性能差が小さいという主張は、データや評価条件に依存する。

**この整理に含まれていないもの**: 反実仮想による説明(counterfactual explanations)、概念に基づく説明(TCAV など)、LLM の内部機構の解析(mechanistic interpretability)、PDP・ALE・permutation importance などの大域的な手法、EBM の原論文。
