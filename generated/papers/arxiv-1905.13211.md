## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Contribution: the paper formally defines algorithmic alignment between a network's computation structure and the algorithmic structure of a reasoning process, and derives a sample complexity bound that decreases with better alignment.([Abstract, p.1](https://arxiv.org/pdf/1905.13211v4#page=1 "We formally deﬁne this algorithmic alignment and derive a sample complexity bound that decreases with better alignment."))
- **c2** Definition (informal): a network aligns with an algorithm if it can simulate the algorithm with a limited number of modules, each of which is simple (low sample complexity); e.g. a GNN simulates Bellman-Ford by learning only the relaxation step, whereas an MLP would have to learn the whole for-loop.([Formalization of algorithmic alignment, p.4](https://arxiv.org/pdf/1905.13211v4#page=4 "Formally, a neural network aligns with an algorithm if it can simulate the algorithm via a limited number of modules, and each module is simple, i.e., has low sample complexity."))
- **c3** GUARANTEE and its assumptions: the theorem linking alignment to sample complexity holds only in a simplifying setting where the network's modules are trained sequentially with auxiliary labels (Theorem 3.6 additionally assumes i.i.d. samples with bounded universe size |S| < N, algorithm stability of the module learner, sequential learning, and Lipschitzness of the learned modules; the paper illustrates module sample complexity with Theorem 3.5, an NTK-based result for overparameterized two-layer MLPs, and says other module bounds can be used). The same paragraph says auxiliary labels are not available in practice, that the same pattern is observed for end-to-end learning in the experiments (empirical, not covered by the theorem), and leaves end-to-end sample complexity analysis to future work.([Better algorithmic alignment implies better generalization, p.5](https://arxiv.org/pdf/1905.13211v4#page=5 "Theorem 3.6 states that, in a simplifying setting where we sequentially train modules of a network with auxiliary labels, the sample complexity bound increases with algorithmic alignment value M."))
- **c4** GNNs and dynamic programming: interpreting GNN aggregation as the DP update, the authors argue Theorem 3.6 suggests a GNN with enough iterations can sample-efficiently learn any DP algorithm with a simple update function such as sum/min/max (shortest paths via Bellman-Ford as the example).([Dynamic programming, p.8](https://arxiv.org/pdf/1905.13211v4#page=8 "Therefore, Theorem 3.6 suggests that a GNN with enough iterations can sample efﬁciently learn any DP algorithm with a simple DP-update function, e.g. sum/min/max."))
- **c5** Scope assumption: the framework is restricted to reasoning tasks whose underlying reasoning process is exact and has clear algorithmic structure; approximation algorithms and unknown structures are left to future work.([Theoretical framework, p.4](https://arxiv.org/pdf/1905.13211v4#page=4 "In this paper, we focus on reasoning tasks whose underlying reasoning process is exact and has clear algorithmic structure."))
- **c6** Evaluation protocol: for each task's dataset (Appendix G), each model's reported test accuracy uses the hyperparameter setting with the best validation accuracy; train, validation and test sets are sampled from the same generator (e.g. 50,000/5,000/5,000 for maximum value difference with 25 treasures), so no larger-input test is described (searched: larger, extrapolat). Section 4 adds that all models are made to perfectly fit their training sets through extensive hyperparameter tuning so test accuracy reflects generalization.([Appendix G (Dataset generation), p.16](https://arxiv.org/pdf/1905.13211v4#page=16 "For each model, we report the test accuracy with the hyperparameter setting that achieves the best validation accuracy."))
- **c7** Relation to sorting: on the maximum value difference task an MLP does not generalize, but if the treasures are sorted by value the MLP achieves perfect test accuracy, which the authors explain as the algorithm reducing to a single subtraction.([Summary statistics, p.7](https://arxiv.org/pdf/1905.13211v4#page=7 "Interestingly, if we sort the treasures by value (Sorted MLP in Fig. 3a), MLP achieves perfect test accuracy."))
