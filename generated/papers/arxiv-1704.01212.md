## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Framework: the forward pass has a message passing phase of T steps (messages summed over neighbors via message functions M_t, node states updated by vertex update functions U_t) and a readout phase computing a graph-level feature vector with a readout function R; M_t, U_t and R are learned differentiable functions, and R must be invariant to permutations of node states for the MPNN to be invariant to graph isomorphism.([Section 2, p.3](https://arxiv.org/pdf/1704.01212v2#page=3 "R operates on the set of node states and must be invariant to permutations of the node states in order for the MPNN to be invariant to graph isomorphism."))
- **c2** The authors reformulate at least eight existing models as MPNNs (including Duvenaud et al. 2015, GG-NN, Interaction Networks, Kearnes et al. 2016, DTNN, and Laplacian-based methods); for Kipf & Welling the message is c_vw h_w with c_vw = (deg(v) deg(w))^(-1/2) A_vw and the update is ReLU(W^t m_v^{t+1}).([Section 2, p.2](https://arxiv.org/pdf/1704.01212v2#page=2 "There are at least eight notable examples of models from the literature that we can describe using our Message Passing Neural Networks (MPNN) framework."))
- **c3** Critique of an existing MPNN: in Duvenaud et al. (2015) the message vector separately sums over connected nodes and connected edges, so the authors conclude that this message passing cannot identify correlations between edge states and node states.([Section 2, p.3](https://arxiv.org/pdf/1704.01212v2#page=3 "It follows that the message passing implemented in Duvenaud et al. (2015) is unable to identify correlations between edge states and node states."))
- **c4** Best variant: an edge network message function (a neural network maps the edge vector e_vw to a d x d matrix A(e_vw) applied to h_w), a set2set readout, and explicit hydrogen atoms as nodes; the authors found including the complete edge feature vector (bond type, spatial distance) and explicit hydrogens very important for a number of targets, and further improved test performance by ensembling the five models with lowest validation error.([Section 8, p.7](https://arxiv.org/pdf/1704.01212v2#page=7 "Our best MPNN variant used the edge network message function, set2set output, and operated on graphs with explicit hydrogens."))
- **c5** Long-range interactions: virtual edges between unconnected pairs and a latent master node connected to every node are introduced so information can travel long distances during propagation; without spatial information, the authors find that augmenting the MPNN with some means of capturing long-range interactions greatly improves performance, and they conclude that allowing long-range interactions via the master node or set2set output is important.([Section 9, p.8](https://arxiv.org/pdf/1704.01212v2#page=8 "Moreover, our results also reveal the importance of allowing long range interactions between nodes in the graph with either the master node or the set2set output."))
- **c6** Caveat on the no-spatial-information and towers experiments (Tables 3 and 4): they were run with a partial charge node feature that is an output of the DFT calculation and so could not be used in an applied setting; the state-of-the-art numbers in Table 2 do not use this feature.([Section 8, p.7](https://arxiv.org/pdf/1704.01212v2#page=7 "This feature is an output of the DFT calculation and thus could not be used in an applied setting."))
- **c7** Protocol: QM9 (130462 molecules, 13 regression targets); 10000 random molecules for validation, 10000 for test, the rest for training; each model/target combination tuned by uniform random hyperparameter search with 50 trials; the validation set is used for early stopping and model selection; targets normalized to mean 0 and variance 1, MSE minimized but MAE evaluated, and results reported as the ratio of MAE to the chemical-accuracy estimate of each target (from Faber et al. 2017). Unless stated otherwise, one model is trained per target.([Section 7, p.7](https://arxiv.org/pdf/1704.01212v2#page=7 "We use the validation set to do early stopping and model selection and we report scores on the test set."))
- **c8** Comparability caveat: the authors use the same train/validation/test split as the baseline study of Faber et al. (2017), but the DTNN numbers are taken as reported in Schütt et al. (2017), whose model was trained on a different split with 100k training samples versus 110k in this paper.([Section 8, p.8](https://arxiv.org/pdf/1704.01212v2#page=8 "The model was trained on a different train/test split with 100k training samples vs 110k used in our experiments."))
- **c9** Limitation and future work: the towers variant improves scalability but further improvements are needed for much larger graphs; the authors name generalization to graphs larger than those in training as an important direction, which 'seems particularly challenging' with spatial information because pairwise distance distributions and the number of incoming messages in fully connected graphs depend on the number of atoms.([Section 9, p.8](https://arxiv.org/pdf/1704.01212v2#page=8 "An important future direction is to design MPNNs that can generalize effectively to larger graphs than those appearing in the training set or at least work with benchmarks designed to expose issues with generalization across graph sizes."))
