## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Setting and assumption: training points are i.i.d. from P = PX x PY|X and the test point from P~ = P~X x PY|X, independently; the conditional distribution of Y given X is assumed to be the same for training and test data (covariate shift). Ordinary conformal prediction relies only on exchangeability, which no longer holds here.([Section 2 (Covariate shift), p.3](https://arxiv.org/pdf/1904.06019v3#page=3 "Notice that the conditional distribution of Y /X is assumed to be the same for both the training and test data."))
- **c2** Guarantee (Corollary 1): if P~X is absolutely continuous with respect to PX and the weights use w = dP~X/dPX, the weighted conformal band has marginal coverage P{Y_{n+1} in C_n(X_{n+1})} >= 1 - alpha for any score function; the same holds if w is known only up to a normalization constant (Remark 3). For weighted split conformal, coverage holds conditional on the preliminary data used to fit the regression function.([Section 2 (Weighted conformal prediction), p.4](https://arxiv.org/pdf/1904.06019v3#page=4 "Assume that ePX is absolutely continuous with respect to PX"))
- **c3** Unlike the unweighted case (upper bound 1 - alpha + 1/(n+1) when there are no ties), the authors state that a meaningful upper bound on coverage for the weighted quantile lemma does not seem possible without further conditions on the weights, because a single weight can be very large.([Section 3 (Remark 5), p.13](https://arxiv.org/pdf/1904.06019v3#page=13 "does not seem possible without further conditions on the weight functions in consideration"))
- **c4** Cost: in general the weighted methodology requires quantiles of a weighted discrete distribution of scores, which is combinatorially hard, but under covariate shift with a known likelihood ratio the computation simplifies and weighted conformal is as easy computationally as ordinary conformal prediction.([Section 4 (Discussion), p.14](https://arxiv.org/pdf/1904.06019v3#page=14 "In this case, known as covariate shift, the new weighted conformal prediction methodology is just as easy, computationally, as ordinary conformal prediction."))
- **c5** Airfoil experiment (UCI, N = 1503, d = 5; 5000 random splits into 25% for fitting a linear-regression mu0, 25% calibration, 50% test; nominal 90%, alpha = 0.1). The shifted test set is synthetic: 25% of the test points resampled with probabilities proportional to exp(x^T beta), so the likelihood ratio is known. Ordinary split conformal had average coverage 90.2% on the unshifted test set but considerably undercovered on the shifted one (82.2%).([Section 2 (Airfoil data example), p.6](https://arxiv.org/pdf/1904.06019v3#page=6 "but for the nonuniformly subsampled test data Dshift (covariate shift, in blue), split conformal considerably undercovers, with its average coverage being 82.2%."))
- **c6** With oracle weights, weighted split conformal brought average coverage back to 90.8%, but the coverage histogram was more dispersed than without shift because the weighted quantile relies on a reduced effective sample size; unweighted split conformal run with that effective number of calibration points lined up very closely with the weighted method.([Section 2 (Airfoil data example), p.6](https://arxiv.org/pdf/1904.06019v3#page=6 "This is because, by using a quantile of the weighted empirical distribution of nonconformity scores, we are relying on a reduced “effective sample size”."))
- **c7** Estimated weights: the likelihood ratio is estimated by a classifier distinguishing training from (unlabeled) shifted test covariates, using the odds p(x)/(1 - p(x)); logistic regression (well-specified here because the tilt is log-linear) and random forests (probabilities clipped to [0.01, 0.99] to avoid infinite weights) each gave 91.0% average coverage, with histograms only a little more dispersed than with oracle weights; random-forest-weighted intervals were more variable and in some cases much longer.([Section 2 (Airfoil data example), p.8](https://arxiv.org/pdf/1904.06019v3#page=8 "Both classiﬁcation approaches deliver weights that translate into good average coverage, being 91.0% for each approach."))
- **c8** Scope of the evidence for estimated weights: the authors state that when the likelihood ratio is not known it can be estimated from unlabeled test covariates, which they showed empirically on a low-dimensional example can still yield correct coverage (the theorem itself assumes the true ratio).([Section 4 (Discussion), p.14](https://arxiv.org/pdf/1904.06019v3#page=14 "When the likelihood ratio d ePX/dPX is not known, it can be estimated given access to unlabeled data (test covariate points), which we showed empirically, on a low-dimensional example, can still yield correct coverage."))
- **c9** Conditional coverage: citing Vovk (2012) and Lei and Wasserman (2014), exact conditional coverage for almost all x0 and all distributions forces infinite expected length at non-atom points. Weighted conformal with a kernel weight centred at x0 gives a locally weighted guarantee, but only for a centre point specified in advance (the band must be recomputed for each x0), so the authors state that many problems in assumption-lean conditional predictive inference remain open.([Section 4 (Towards local conditional coverage?), p.15](https://arxiv.org/pdf/1904.06019v3#page=15 "We have only described a way to satisfy such a property if the center point x0 were speciﬁed in advance."))
