## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Motivation: existing RM evaluations use validation sets from earlier RLHF data such as Anthropic Helpful and Harmless or OpenAI Learning to Summarize, which (citing Wang et al., 2024) are known to have accuracy ceilings between 60 and 70% due to inter-annotator disagreement; newer preference datasets such as UltraFeedback, UltraInteract and Nectar have no test sets.([Introduction, p.2](https://arxiv.org/pdf/2403.13787v2#page=2 "which are known to have ceilings on accuracy between 60 and 70% due to inter-annotator disagreement (Wang et al., 2024)."))
- **c2** Background: classifier RMs are trained with the Bradley-Terry maximum-likelihood loss on prompt-chosen-rejected trios; DPO models are treated as implicit reward models with r(x, y) = beta log pi(y|x)/pi_ref(y|x) + beta log Z(x), so two completions are compared through their log-ratios against the reference model.([Section 3, p.4](https://arxiv.org/pdf/2403.13787v2#page=4 "Direct Preference Optimization solves the RLHF problem with- out needing to learn a separate reward model."))
- **c3** Scoring: for each trio the RM scores prompt-chosen and prompt-rejected and a win is counted if the chosen score is higher; subset scores are accuracies, so a random model gets 50%. Section scores are per-prompt weighted averages over subsets, except that Reasoning upweights the PRM-Math subset so code and math count equally and Prior Sets uses an unweighted average; the final score weights Prior Sets at 0.5 because of noise and lack of clearly defined tasks.([RewardBench Scoring, p.5](https://arxiv.org/pdf/2403.13787v2#page=5 "Given the binary classification task, a random model achieves a result of 50%."))
- **c4** Data: Chat (AlpacaEval and MT Bench pairs), Chat Hard (MT Bench pairs with similar ratings and LLMBar adversarial data), Safety (custom XSTest, Do-Not-Answer and an in-development AI2 refusals dataset), Reasoning (HumanEvalPack correct vs buggy code, PRM800k reference vs incorrect answers) and Prior Sets; all subsets are either manually verified or curated from previous evaluation datasets with manual verification, and the core dataset has 2958 prompts, all single-turn. The dataset is released under ODC-BY and the code under Apache 2.0.([Appendix F, p.29](https://arxiv.org/pdf/2403.13787v2#page=29 "In total there are 2958 prompts in REWARDBENCH."))
- **c5** Length control: citing Singhal et al. (2023) on length bias, the benchmark was designed so that chosen responses are of similar length or shorter than rejected ones; the AlpacaEval Length subset pairs models of notably different capability with the same average length. The authors say more detailed statistical tests are needed to fully understand this.([Appendix B, p.16](https://arxiv.org/pdf/2403.13787v2#page=16 "we designed REWARDBENCH so that the chosen responses are either a similar length or shorter than the rejected responses."))
- **c6** DPO evaluation caveats: some released DPO models do not clearly document which reference model was used, which can make benchmarking unclear; a reference-free comparison is possible but, without normalization, carries a length penalty; and using a 'wrong' (similar but different) reference model reduced DPO reward-model performance to about the random baseline. The authors also note DPO models are KL-regularized while classifier RMs are not, and are usually trained for more than one epoch.([Appendix B, p.16](https://arxiv.org/pdf/2403.13787v2#page=16 "We also experimentedwith using the “wrong” reference model, i.e. a similar but different base model, and found that this reduced the DPO trained RM performance to similar levels as the random baseline."))
- **c7** Prior test sets: some models scoring strongly on Prior Sets were trained on the training splits of Anthropic HH, SHP and Learning to Summarize while other top classifiers were not; combined with the very low average score of DPO models on these sets, the authors say substantial research is needed to understand the full limitations of these datasets.([Section 5.3, p.9](https://arxiv.org/pdf/2403.13787v2#page=9 "Combining this with the very low average score of DPO models on these test sets indicates that substantial research is needed to understand the full limitations of these previous datasets."))
- **c8** Stated limitations: no human preference data is collected (except for specific subsets chosen-rejected pairs are obtained semi-automatically and then manually validated); formats in some domains such as reasoning might include spurious correlations; whether and how benchmark results correlate with downstream training is unresolved; and data contamination is possible if models were trained on AlpacaEval or MT-Bench data. The conclusion likewise calls correlating RewardBench performance with RLHF usefulness a crucial next step.([Appendix A, p.16](https://arxiv.org/pdf/2403.13787v2#page=16 "Another unresolved question is whether and how the benchmark results correlate with downstream training."))
