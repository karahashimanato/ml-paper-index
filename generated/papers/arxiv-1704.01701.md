## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Relation to B&B: B&B is used inside an ML method (rule-list learning) to find the optimal rule list according to the training objective (a regularized empirical risk, within the class of rule lists assembled from pre-mined frequent itemsets), with a certificate of optimality that allows investigating how close other models (e.g. from greedy algorithms) are to optimal.([Introduction, p.2](https://arxiv.org/pdf/1704.01701v4#page=2 "Specifically, we introduce a special branch-and bound algorithm, called Certifiably Optimal RulE ListS (CORELS), that provides the optimal solution according to the training objective, along with a certificate of optimality."))
- **c2** Bounds: CORELS keeps a lower bound on the objective achievable by each incomplete rule list (prefix) and prunes the prefix and all its extensions when the bound exceeds the best rule list found so far; the hierarchical bound is the fraction of data captured and misclassified by the prefix plus lambda times the prefix length.([Introduction, p.3](https://arxiv.org/pdf/1704.01701v4#page=3 "Within its branch-and-bound procedure, CORELS maintains a lower bound on the minimum value of R that each incomplete rule list can achieve."))
- **c3** Scope of the optimality guarantee: optimality is with respect to the regularized training objective R (misclassification + lambda x length) over rule lists built from pre-mined rules; because each rule in an optimal rule list must have sufficiently large support (Theorem 10), rule lists can be built from frequent itemsets while preserving the guarantee of finding a globally optimal rule list from the pre-mined rules.([Optimization Framework, p.8](https://arxiv.org/pdf/1704.01701v4#page=8 "This allows us to construct rule lists from frequent itemsets, while preserving the guarantee that we can find a globally optimal rule list from pre-mined rules."))
- **c4** Contrast with greedy learners (as characterized by the authors): because the optimal decision tree problem is hard, algorithms such as CART and C4.5 do not explore the search space beyond greedy splitting, and many decision-list and associative classification methods construct rule lists greedily; the authors view their problem as a version of the optimal decision tree problem changed by regularization.([Related Work, p.4](https://arxiv.org/pdf/1704.01701v4#page=4 "Because the optimal decision tree problem is hard, there are a huge number of algorithms such as CART (Breiman et al., 1984) and C4.5 (Quinlan, 1993) that do not perform exploration of the search space beyond greedy splitting."))
- **c5** Baseline protocol: logistic regression, SVM, AdaBoost, CART, C4.5, random forests and RIPPER were run with standard R packages at default parameter settings (a separate figure varies CART/C4.5/RIPPER/SBRL parameters), with 10-fold cross-validation on the ProPublica COMPAS and NYCLU stop-and-frisk data; CORELS and SBRL receive the same antecedent sets, while the other algorithms receive binary features corresponding to the single-clause antecedents.([Experiments, p.45](https://arxiv.org/pdf/1704.01701v4#page=45 "We use standard R packages, with default parameter settings, for the first seven algorithms."))
- **c6** Finding (ProPublica recidivism): no statistically significant differences in test accuracy across algorithms; variation across folds exceeded variation across algorithms, and all were similar to the COMPAS black box.([Experiments, p.45](https://arxiv.org/pdf/1704.01701v4#page=45 "Figure 9 shows that for the ProPublica data set, there were no statistically significant differences in test accuracies across algorithms, the difference between folds was far larger than the difference between algorithms."))
- **c7** Limitation: although scaling well in the number of observations, CORELS could have difficulty proving optimality with many possibly relevant, highly correlated features (it also does not directly handle continuous variables and is not designed for non-interpretable raw features such as images).([Conclusion, p.57](https://arxiv.org/pdf/1704.01701v4#page=57 "While our approach scales well to large numbers of observations, it could have difficulty proving optimality for problems with many possibly relevant features that are highly correlated, when large regions of the search space might be challenging to exclude."))
