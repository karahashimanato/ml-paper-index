## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Definition: a GSSM has a finite state space S with mem(S) = log|S| bits, updated by S_i = u(S_{i-1}, x_i) with output r(S_i). The definition constrains only input-dependent memory (activations) and not parameters or the run-time of state updates; the authors argue this only strengthens their lower bound.([Section 2.1, p.3](https://arxiv.org/pdf/2402.01032v2#page=3 "Since our main goal is to show a lower bound on the state space memory, leaving all other considerations unconstrained only strengthens our results."))
- **c2** Transformer construction (Theorem 2.3): for all n there is a depth-2 transformer of dimension O(n log D) whose error on any length-L copy distribution (2n <= L <= D^n) is below the probability of repeated n-grams; it hashes n-grams using Hard-ALiBi and copies perfectly as long as no n-gram pattern repeats. Remark 2.6: precision is not limited, but the results hold for finite precision with O(log(log(L))) bits.([Section 2.2, p.3](https://arxiv.org/pdf/2402.01032v2#page=3 "The copy algorithm given in Algorithm 1 (and similarly, our transformer construction) can perfectly copy the input sequence, as long as there are no repeated n-gram patterns in the input."))
- **c3** GSSM lower bound (Theorem 2.7, Corollary 2.8): any GSSM has error > 1 - |S|/D^L on the uniform copy distribution, so any GSSM with mem(S) < L log(D) - 1 has error > 1/2; the authors call this intuitive, since copying requires storing the input in the state.([Section 2.3, p.4](https://arxiv.org/pdf/2402.01032v2#page=4 "This is intuitive: to be able to copy the entire input sequence, the model needs to store it in its state space, which requires the memory to grow linearly with the sequence length."))
- **c4** Scope of the theory: it studies representational expressivity, not whether the representations are learned, and in practice a large GSSM may have enough capacity to hold the entire input (e.g. 1000 32-bit floats can store at least 2000 tokens from a 50K vocabulary); hence the synthetic and pretrained-model experiments.([Introduction, p.1](https://arxiv.org/pdf/2402.01032v2#page=1 "Our theory studies representation expressivity, but not whether these representations will be learned."))
- **c5** Synthetic-experiment setup: Mamba and transformers are set to a similar parameter count (about 160M), the LSTM is the largest the authors managed to train (about 40M); per Appendix A.2, Hard-ALiBi's number of masked heads and Mamba's state dimension were swept, and the learning rate was swept only for LSTM and Mamba.([Section 3.1, p.4](https://arxiv.org/pdf/2402.01032v2#page=4 "In all our experiments, we set the model hyperparameters so that the Mamba and transformers have a similar number of parameters (≈160 million parameters)."))
- **c6** Data efficiency: training on strings of random length up to 300 and evaluating in-distribution string-level accuracy, the authors observe that transformers need 100x fewer samples than the best GSSMs to learn the copy task; LSTMs did not learn length-300 strings even at the character level.([Section 3.2, p.5](https://arxiv.org/pdf/2402.01032v2#page=5 "We observe that the transformers need 100x less samples than the best GSSMs to learn the copy task."))
- **c7** Counterexample where GSSMs do well: in the prefix-key n-gram lookup task (key given before the sequence, so the full input need not be stored) GSSMs achieve perfect length generalization and even outperform NoPE and ALiBi transformers (but not Hard-ALiBi); the authors hypothesize this may be due to those positional embeddings, and conclude GSSMs seem memory limited but can be effective when only a summary of the input is needed.([Section 3.5, p.6](https://arxiv.org/pdf/2402.01032v2#page=6 "Indeed, GSSMs achieve perfect length-generalization on this variant."))
- **c8** Pretrained-model comparison conditions: Pythia transformers (410M-2.8B) are compared with Mamba models of similar sizes, all pretrained on the Pile with the same tokenizer; the Mamba models generally have slightly lower perplexity on the training set for a given size. Evaluation is without finetuning, string-level accuracy (F1 for SQuAD) over 10 batches of 64 (50 questions for QA), greedy decoding.([Section 4.1, p.7](https://arxiv.org/pdf/2402.01032v2#page=7 "The Mamba models generally have slightly lower perplexity on the training set for a given size."))
- **c9** Discussion: the authors emphasize that state space models have advantages (memory and compute not growing with input length, better tracking of state variables, citing Liu et al., 2023a) and suggest future work on hybrid architectures that give state space models an attention-like mechanism for retrieving text from the input.([Section 6, p.9](https://arxiv.org/pdf/2402.01032v2#page=9 "We therefore believe that future work should focus on building hybrid architectures that endow state space models with an attention-like mechanism, allowing them to retrieve relevant pieces of text from their input."))
