## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Motivation: static, ground-truth benchmarks are mostly not open-ended, and because their test sets are static they can become contaminated over time (citing Yang et al., 2023), which undermines reliability; for many complex tasks a definitive ground truth is hard or impossible to establish.([Introduction, p.1](https://arxiv.org/pdf/2403.04132v1#page=1 "Secondly, the test sets in these benchmarks are static, meaning they can become contaminated over time, which undermines the reliability of the evaluation results (Yang et al., 2023)."))
- **c2** Interface: because a consistent grading rubric across many users is difficult, users compare two anonymous models' responses side-by-side and vote for the better one instead of giving absolute scores; no input prompts are preset, users may keep chatting until they can pick a winner, and 'tie' / 'both are bad' buttons are offered.([Section 3.1, p.3](https://arxiv.org/pdf/2403.04132v1#page=3 "Hence, we adopt a pairwise comparison mechanism where users only need to compare two model responses and vote for the better one, instead of requiring users to provide an absolute score."))
- **c3** Data hygiene: to ensure anonymity, conversations containing model identity (model names such as GPT, Claude, or company names such as OpenAI, Anthropic) are filtered by keywords, and OpenAI's moderation API flags unsafe content (3% of requests).([Section 3.2, p.3](https://arxiv.org/pdf/2403.04132v1#page=3 "To ensure anonymity, we use keywords to filter out conversations containing model identity such as model name (e.g., GPT, Claude) or companies (e.g., OpenAI, Anthropic)."))
- **c4** Score: the target is the vector of Bradley-Terry coefficients minimizing the binary cross-entropy (by default targeting a uniform distribution over model pairs). Although BT assumes a parametric form for win rates, the authors cite Huber et al. (1967) and White (1982) that the MLE is still asymptotically normal under misspecification if the sandwich covariance is used; earlier versions of the leaderboard reported Elo scores, which were replaced because BT coefficients are better for statistical estimation.([Section 4, p.4](https://arxiv.org/pdf/2403.04132v1#page=4 "show that maximum likelihood estimators are still asymptotically normal even when these assumptions do not hold, so long as the so-called “sandwich” covariance matrix is used"))
- **c5** Approximate ranking: given a confidence set with uniform coverage 1 - alpha, model m's rank is the number of models whose lower bound exceeds m's upper bound, which implies that with high probability no model's performance is understated (the opposite guarantee is obtained by interchanging inf and sup); the uniform set is a chi-squared CLT interval using the sandwich variance of the logistic regression.([Section 5, p.5](https://arxiv.org/pdf/2403.04132v1#page=5 "i.e., with high probability, no model’s performance is understated."))
- **c6** Anomalous users: each new vote gets a p-value comparing it with the historical ratings for the same model pair (valid under exchangeability, proof in Appendix C), combined with Fisher's test and flagged at 5 randomly chosen vote counts between 1 and 100 (chosen randomly so users cannot strategize). The authors call this a heuristic application that seems to work well in small-scale tests (25 manually identified anomalous users and 25 normal users).([Section 5.1, p.5](https://arxiv.org/pdf/2403.04132v1#page=5 "Despite the heuristic application of this procedure, it seems to work well in our small-scale tests reported in Table 5."))
- **c7** Prompt diversity: BERTopic-style topic modeling (text-embedding-3-small, UMAP to 5 dimensions, HDBSCAN with minimum cluster size 32, GPT-4-Turbo labels) finds 600 clusters; the largest covers only 1% of prompts, the rest quickly drop below 0.5%, and inter-cluster similarity is small, which the authors read as a long-tail, diverse distribution.([Section 6.1, p.6](https://arxiv.org/pdf/2403.04132v1#page=6 "We observe that the largest cluster only accounts for 1% of the entire set and the rest quickly drop to <0.5%, and the similarity between clusters is small, showing a long-tail and diverse distribution."))
- **c8** Vote quality: on battles relabeled by experts in two setups, agreement between crowd users and experts was 72% to 83%, versus 79.4% and 89.8% between the two experts. Expert disagreement is attributed mostly to prompts without a ground-truth answer, and the crowd-vs-expert gap (5%-10%) mostly to crowd users making mistakes or overlooking factual errors.([Section 6.3, p.7](https://arxiv.org/pdf/2403.04132v1#page=7 "To summarize, we observe high agreement rates (72% to 83%) between Arena crowd-user and experts in both setup."))
- **c9** Stated limitations: the user base is anticipated to consist primarily of LLM hobbyists and researchers, which may bias the user distribution; prompts come predominantly from the online chat interface and might not reflect production or specialized-domain usage, potentially skewing the prompt distribution; and the study assesses helpfulness while overlooking safety.([Section 8, p.8](https://arxiv.org/pdf/2403.04132v1#page=8 "This source might not accurately reflect the real-world usage of LLMs in production environments or specialized domains, potentially leading to a skewed prompt distribution."))
