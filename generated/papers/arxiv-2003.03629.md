## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Main finding: adding extra randomly generated noise features and then running bagging (AugBagg) can lead to dramatic improvements in out-of-sample accuracy, sometimes outperforming even an optimally tuned random forest; consequently, variable importance based on improved accuracy may be deeply flawed.([Abstract, p.1](https://arxiv.org/pdf/2003.03629v2#page=1 "Surprisingly, we demonstrate that this simple act of including extra noise variables in the model can lead to dramatic improvements in out-of-sample predictive accuracy, sometimes outperforming even an optimally tuned traditional random forest."))
- **c2** Definition of the added features: the noise features N need only be conditionally independent of Y given X, so they may be correlated with the original features; the authors note that how they are generated can greatly affect performance.([Section 2, p.4](https://arxiv.org/pdf/2003.03629v2#page=4 "Importantly, we insist only that N be generated conditionally independent of Y given X."))
- **c3** When it helps: in the authors' simulations (linear model, n = 100, p = 5 signal features, 500 repetitions per point, random forests with each mtry as reference lines), gains appear most dramatic at low SNRs, while correlated noise features can keep improving performance at higher SNRs; with independent noise features performance deteriorates with the number of added features at moderate SNRs.([Discussion, p.23](https://arxiv.org/pdf/2003.03629v2#page=23 "Performance gains appear most dramatic at low SNRs, though the introduction of correlated noise features can continue to improve performance even at higher SNRs."))
- **c4** Real-data protocol: on 14 regression datasets (9 low- and 5 high-dimensional), the number of added features q is tuned over {p/2, p, 3p/2, 2p} and their correlation r over {0, 0.1, 0.4, 0.7, 0.9}, extra noise is injected into the response, and performance is relative test error versus bagging. No description of the data used to select q and r or of how the test error is estimated on these datasets was found in the text (searched for validation, cross-validation, out-of-bag, hold, test set).([Section 3, p.8](https://arxiv.org/pdf/2003.03629v2#page=8 "Since diﬀerent datasets have diﬀerent numbers of original features, q is tuned over p/2, p, 3p/2 and 2p."))
- **c5** Theoretical motivation (simplified model, OLS ensembles rather than trees): building on LeJeune et al. (2019), under their asymptotic assumptions (e.g., identity covariance, feature and row subsampling), a subsampled OLS ensemble built on a design augmented with independent noise features behaves like the ensemble on the original design with a smaller feature-subsampling rate, i.e., a more regularized estimator.([Section 4, p.14](https://arxiv.org/pdf/2003.03629v2#page=14 "eﬀect as constructing the ensemble on the original design with a smaller subsampling rate, thereby producing a more regularized estimator."))
- **c6** Variable importance: using the test of Williamson et al. (2020) with bagged ensembles of 500 trees, tests that drop the noise features under investigation rejected the null (declaring pure noise features important) far above the nominal 5% level: nearly 30% of the time at low SNRs with many tested features when the noise features are independent of the original features.([Section 5, p.19](https://arxiv.org/pdf/2003.03629v2#page=19 "the tests that drop the features under investigation reject nearly 30% of the time at low SNRs when a large number of features are being tested."))
- **c7** Caveat on those rejection rates: the authors caution that the particular rejection probabilities should not be read as guidelines; inflation depends on the data and on the power of the test (more powerful tests would reject even more often).([Section 5, p.19](https://arxiv.org/pdf/2003.03629v2#page=19 "These empirical results should in no way be seen as guidelines for how often or under what settings such tests will produce inﬂated rejection proportions."))
- **c8** Replacement-style tests (replacing features with random substitutes, as in Mentch and Hooker 2016 and Coleman et al. 2019) kept close to the nominal level when the substitutes had the same distribution as the tested features, but when correlated noise features were replaced by independent noise the test rejected with very high probability across all but the lowest SNRs.([Section 5, p.21](https://arxiv.org/pdf/2003.03629v2#page=21 "Here we again notice a troubling trend: the test has a very high probability of rejecting across all but the lowest SNRs and this probability appears to increase with q."))
- **c9** Interpretation and limitations: the authors do not conclude the tests are wrong, only that rejection means the features improve performance when included; they stress AugBagg should not replace random forests, as it increases computation and they cannot offer default values for q and r likely to work broadly.([Discussion, p.23](https://arxiv.org/pdf/2003.03629v2#page=23 "we stress that the procedure should not be seen as replacing or superseding more eﬃcient procedures like random forests."))
