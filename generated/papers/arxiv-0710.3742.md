- **c1** Model assumptions: the sequence is divided into non-overlapping product partitions whose boundaries are the changepoints; within each partition the data are i.i.d. given partition parameters, the partition parameters are themselves i.i.d., and a discrete prior Pgap(g) is placed on the interval between changepoints.([Introduction, p.1](https://arxiv.org/pdf/0710.3742v1#page=1 "We further assume that for each partition ρ, the data within it are i.i.d. from some probability distribution"))
- **c2** Goal: unlike most Bayesian changepoint work, which is offline and retrospective (segmentation, posterior sampling of changepoint locations), the paper targets online causal predictive filtering, i.e. an accurate distribution of the next datum given only data already observed.([Introduction, p.1](https://arxiv.org/pdf/0710.3742v1#page=1 "Rather than retrospective segmentation, we focus on causal predictive ﬁltering; generating an accurate distribution of the next unseen datum in the sequence, given only data already observed."))
- **c3** Run-length recursion: the joint distribution over the current run length and the data is computed recursively by message passing, needing only (1) the prior over r_t given r_{t-1} and (2) the predictive distribution of the new datum given the data since the last changepoint; the marginal predictive is obtained by integrating over the run-length posterior.([Recursive Run Length Estimation, p.2](https://arxiv.org/pdf/0710.3742v1#page=2 "We can thus generate a recursive message-passing algorithm for the joint distribution over the current run length and the data"))
- **c4** Hazard function: the conditional changepoint prior has nonzero mass at only two outcomes (run length grows by one, or drops to zero), which gives the algorithm its efficiency; the hazard H(τ) is derived from Pgap, and when Pgap is geometric with timescale λ the process is memoryless and the hazard is constant at 1/λ.([The Changepoint Prior, p.2](https://arxiv.org/pdf/0710.3742v1#page=2 "is a discrete exponential (geometric) distribution with timescale λ, the process is memoryless and the hazard function is constant"))
- **c5** Initialization: two boundary conditions are considered: if a changepoint is known to occur just before the first datum, all initial run-length mass is placed at zero; if only a recent subset of the data is observed, the initial run length prior is the normalized survival function of Pgap.([Boundary Conditions, p.3](https://arxiv.org/pdf/0710.3742v1#page=3 "In such cases we place all of the probability mass for the initial run length at zero"))
- **c6** Predictive model: conjugate-exponential models are convenient because inference needs a finite number of sufficient statistics that can be updated incrementally per run-length hypothesis; only this exact case is addressed, and compact approximations are mentioned for cases where exact predictive distributions are not available.([Conjugate-Exponential Models, p.3](https://arxiv.org/pdf/0710.3742v1#page=3 "We will only address the exact case in this paper"))
- **c7** Cost and pruning: per-time-step space and time complexity are linear in the number of data points observed so far; discarding run-length tail mass below a threshold (e.g. 10^-4) gives constant average complexity per iteration of the order of the expected run length E[r], but the worst case is still linear in the data.([Computational Cost, p.4](https://arxiv.org/pdf/0710.3742v1#page=4 "This yields a constant average complexity per iteration on the order of the expected run length E[r], although the worst-case complexity is still linear in the data."))
- **c8** Experimental protocol: three real-world datasets (well-log nuclear magnetic response with a Gaussian model, 1972-75 Dow Jones daily returns with zero-mean Gaussian and changing variance, coal mine disasters as a Poisson process), each with a discrete exponential prior on the changepoint interval (λgap = 250, 250 and 1000 respectively) and stated prior parameters. No detection metric, comparison method, or explicit rule for declaring a changepoint from the posterior was found in the text (searched for threshold, declare, select).([Well-Log Data, p.4](https://arxiv.org/pdf/0710.3742v1#page=4 "Notice that the drops to zero run-length correspond well with the abrupt changes in the mean of the data."))
- **c10** Marginal predictive (Eq. 1): P(x_{t+1} | x_1:t) = sum over r_t of P(x_{t+1} | r_t, x_t^(r)) P(r_t | x_1:t), where x_t^(r) is the data associated with run r_t.([Recursive Run Length Estimation, p.2](https://arxiv.org/pdf/0710.3742v1#page=2 "We then integrate over the posterior distribution on the current run length to ﬁnd the marginal predictive distribution:"))
- **c11** Run-length posterior and recursion (Eq. 2-3): P(r_t | x_1:t) = P(r_t, x_1:t) / P(x_1:t), and P(r_t, x_1:t) = sum over r_{t-1} of P(r_t | r_{t-1}) P(x_t | r_{t-1}, x_t^(r)) P(r_{t-1}, x_1:t-1).([Recursive Run Length Estimation, p.2](https://arxiv.org/pdf/0710.3742v1#page=2 "we write the joint distribution over run length and observed data recursively."))
- **c12** Changepoint prior and hazard (Eq. 4-5): P(r_t | r_{t-1}) = H(r_{t-1}+1) if r_t = 0, 1 - H(r_{t-1}+1) if r_t = r_{t-1} + 1, and 0 otherwise; the hazard is H(tau) = P_gap(g = tau) / sum_{t=tau}^{inf} P_gap(g = t).([The Changepoint Prior, p.2](https://arxiv.org/pdf/0710.3742v1#page=2 "The function H(τ) is the hazard function."))
- **c13** Algorithm 1 steps: evaluate the predictive probability pi_t^(r) of the new datum under each run length; growth probabilities P(r_t = r_{t-1}+1, x_1:t) = P(r_{t-1}, x_1:t-1) pi_t^(r) (1 - H(r_{t-1})); changepoint probability P(r_t = 0, x_1:t) = sum over r_{t-1} of P(r_{t-1}, x_1:t-1) pi_t^(r) H(r_{t-1}); evidence P(x_1:t) is the sum over r_t; the run-length distribution is the joint divided by the evidence.([Algorithm 1, p.3](https://arxiv.org/pdf/0710.3742v1#page=3 "Algorithm 1: The online changepoint algorithm with"))
