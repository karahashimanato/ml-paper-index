## 主張

出典のリンクは原論文PDFの該当ページを開く。リンクにカーソルを合わせると原文の引用が表示される。

- **c1** Method: self-attention is expressed as a linear dot-product of kernel feature maps, and the associativity of matrix products reduces the complexity from O(N^2) to O(N) in the sequence length N; the authors state this permits an iterative implementation that accelerates autoregressive transformers and reveals their relationship to RNNs.([Abstract, p.1](https://arxiv.org/pdf/2006.16236v3#page=1 "we express the self-attention as a linear dot-product of kernel feature maps and make use of the associativity property of matrix products to reduce the complexity"))
- **c2** Cost analysis: softmax attention costs O(N^2 max(D, M)) multiplications and additions, linear attention with feature maps of dimension C costs O(NCM). The feature map of the exponential kernel is infinite dimensional, so exact softmax attention cannot be linearized; a degree-2 polynomial kernel has an exact finite feature map with cost O(N D^2 M), favorable when N > D^2.([Section 3.2.1, p.3](https://arxiv.org/pdf/2006.16236v3#page=3 "Note that the feature function that corresponds to the exponential kernel is inﬁnite dimensional, which makes the linearization of exact softmax attention infeasible."))
- **c3** For their experiments (which deal with smaller sequences) the authors use phi(x) = elu(x) + 1, which gives a positive similarity and O(NDM) cost; elu is preferred over relu to avoid zero gradients for negative inputs. This feature map does not approximate the softmax kernel; the authors state that experimentally it performs on par with the full transformer.([Section 3.2.1, p.4](https://arxiv.org/pdf/2006.16236v3#page=4 "to avoid setting the gradients to 0 when x is negative"))
- **c4** Causal masking: with S_i and Z_i defined as prefix sums, each can be updated from S_{i-1}, Z_{i-1} in constant time. A naive implementation stores all S_i, multiplying memory by max(D, M); the authors derive the gradients as cumulative sums so that forward and backward passes run in linear time and, with respect to the sequence length, constant memory for the cumulative sums (overall complexity O(NCM), memory O(N max(C, M))).([Section 3.3.1, p.4](https://arxiv.org/pdf/2006.16236v3#page=4 "This allows us to compute both the forward and backward pass of causal linear attention in linear time and constant memory."))
- **c5** Recurrent view: any transformer layer with causal masking can be written as an RNN with two hidden states, the attention memory s_i = s_{i-1} + phi(x_i W_K)(x_i W_V)^T and the normalizer memory z_i; the authors note the formulation imposes no constraint on the feature function and could in theory represent any transformer, even ones using softmax attention.([Section 3.4, p.5](https://arxiv.org/pdf/2006.16236v3#page=5 "any transformer layer with causal masking can be written as a model that, given an input, modiﬁes an internal state and then predicts an output, namely a Recurrent Neural Network (RNN)."))
- **c6** Measurement of computational requirements: attention plus its gradients are computed on synthetic inputs of length 2^9 to 2^16, batch size scaled inversely with length, reporting peak GPU memory and time per sample on an NVidia GTX 1080 Ti (11GB); each method is run up to the longest sequence fitting in memory (4,096 for softmax, 16,384 for lsh-4 and lsh-8). Reformer is run without reversible layers, which the authors say does not matter because only the self-attention layer's memory is measured.([Section 4.1.2, p.6](https://arxiv.org/pdf/2006.16236v3#page=6 "For this benchmark we use an NVidia GTX 1080 Ti with 11GB of memory."))
- **c7** CIFAR-10 image generation is a fixed wall-clock comparison: all models are trained for 7 days on one GPU (NVidia P40, 24GB); the full softmax transformer fits only batch size 1 while linear and Reformer use batch size 4, so the bits/dim comparison reflects efficiency per GPU hour rather than equal training. Baseline softmax uses the default PyTorch implementation; a faster softmax variant that caches keys and values is compared only in the supplementary material.([Section 4.2.2, p.7](https://arxiv.org/pdf/2006.16236v3#page=7 "Since the sequence length is almost 4 times larger than for the previous experiment, the full transformer can only be used with a batch size of 1 in the largest GPU that is available to us, namely an NVidia P40 with 24GB of memory."))
- **c8** Quality gap: on WSJ speech recognition (non-autoregressive, CTC loss) the softmax transformer achieves lower phone error rate than all baselines including the linear transformer, but is significantly slower; linear is reported to be more than 3x faster per epoch.([Section 4.3, p.8](https://arxiv.org/pdf/2006.16236v3#page=8 "Note that the softmax transformer, achieves lower phone error rate in comparison to all baselines, but is signiﬁcantly slower."))
